# `district.json` — контракт генератора района (schema_version 1)

Машиночитаемая схема: `worldgen/schema.json` (JSON Schema draft-07). Этот файл — описание смысла полей.
Генератор и Unreal-сторона **не меняют формат без записи в PR**.

## Система координат и единицы
- Метры. **X — вправо, Y — вперёд (от моря к городу), Z — вверх.** Уровень воды `z = 0`.
- Игровая арена: `x ∈ [-800, 800]`, `y ∈ [0, 1200]` (1,6 × 1,2 км). Рельеф шире: `y ∈ [-400, 1200]` — на море перед ареной приходится
  спуск и дно, по которому мех выходит на берег.
- Углы `yaw_deg` — градусы против часовой стрелки от оси +X в плоскости XY.
- Все полигоны — список `[x, y]`, без повтора первой точки. Все числа округлены (координаты до 0,1 м, высоты до 0,01 м).

## Корень
| Поле | Тип | Смысл |
|---|---|---|
| `schema_version` | `1` | версия формата |
| `seed` | int | сид генерации |
| `bounds` | object | `playable` (арена) и `terrain` (весь рельеф), единицы, оси |
| `terrain` | object | метаданные карты высот (ниже) |
| `water` | object | `level_z`, `sea_floor_z`, `shoreline` (ломаная берега), `flood_zones` (id опасных зон) |
| `roads` | array | улицы |
| `blocks` | array | кварталы, площадь, площадки |
| `buildings` | array | обычные и постановочные здания |
| `infrastructure` | object | порт, подстанция, метро, ограждения, id эстакады |
| `props` | array | автомобили, деревья, фонари, скамейки |
| `pois` | array | точки интереса и камеры |
| `hazards` | array | зоны опасности |

## `terrain`
Карта высот `heightmap.r16` (рядом с `district.json`): **1009 × 1009**, 16 бит, little-endian, без заголовка — формат Unreal Landscape.
- Размер области: 1600 × 1600 м (`extent`), шаг `cell_size_m ≈ 1,587` м.
- Порядок строк `row_order = "y_ascending"`: строка 0 — `y_min` (море), столбец 0 — `x_min`. Если начало координат ландшафта в Unreal
  оказывается у `y_max`, при импорте перевернуть ось Y.
- Кодирование высоты: `z_m = (value − 32768) / 128` (`height_encoding`): значение 32768 — уровень воды; 1 единица = 1/128 м, что соответствует
  Landscape с масштабом Z = 100.
- Профиль: от берега в сторону моря пологий спуск 0 … −25 м на ~175 м (уклон не круче 14°), дальше дно −25 м. На суше — пляж, поднятая
  набережная (~+2,8 м), медленный подъём вглубь. Две низины (`hazards`, `kind = flood`) лежат ниже окружающей земли примерно на 2 м.
- Под каждым зданием выровнена площадка (`base_z` совпадает с высотой рельефа в центре).

## `roads[]`
`{id, kind, name, width, points[[x,y]…], dead_end}`. `kind`: `promenade` (набережная, 40 м), `avenue` (90 м, две штуки), `street` (44–60 м),
`alley` (40 м, тупик `dead_end: true` — для «загнать в узкую улицу»). Ширина всегда 40–90 м. Площадь — квартал с `kind = plaza`
(улица, проходившая через неё, разрезана на две части).

## `blocks[]`
`{id, kind, district, col, row, polygon, name?, sub_block?}`. `kind`: `block` (120–250 м), `site` (широкая промышленная/портовая площадка 320 м),
`plaza`. `sub_block: true` — половина квартала, разрезанного тупиковой улицей (уже 120 м). `district`: `downtown / residential / industrial / mixed / civic`.

## `buildings[]`
Общие поля: `id`, `type` (`generic | hero`), `block_id` (у эстакады `null`), `district`, `building_type`
(`office | residential | industrial | parking | stadium | overpass | crane`), `facade_style`, `footprint` (полигон), `height` (м), `floors`
(по 4 м), `base_z`, `yaw_deg`, опционально `structure`, `parts`, `hazard`.
- `generic`: высота 30–200 м; не менее 25 % имеют `structure` (в `seed 1` — каждое третье).
- `hero` — ровно 6, `hero_kind`:

| `hero_kind` | Что | Размер | Особенности |
|---|---|---|---|
| `glass_tower` | стеклянная башня | 62×62 м, **220 м**, 55 этажей | 5 ярусов, 2 линии слабости |
| `stadium` | стадион | эллипс 204×120 м, 48 м | кольцо колонн, крыша на мачтах |
| `residential_complex` | жилой комплекс «подкова» | ~120×140 м, 72 м | двор открыт от улицы |
| `overpass` | эстакада | **405 м** × 26 м, настил на +14 м | пролёты — независимые ярусы; `deck_z`, `length` |
| `port_crane` | портальный кран | 40×24 м, 95 м | стрела над водой (`parts[0]`) |
| `power_station` | электростанция | 130×85 м, 40 м | трубы 120 м в `parts`, `hazard = electrical` |

### `structure` — граф конструкции (разрушение, §17–§18)
```
structure: {
  stacked: true,                 // false у эстакады: пролёты независимы
  columns:  [{id, pos[x,y,z], height, strength, tier, role: regular|weak, holds?}],
  floors:   [{id, z, supports:[column ids], mass, tier}],
  tiers:    [{index, z, height, mass, com[x,y]}],        // ярус = группа этажей на одних колоннах
  weak_lines: [{id, columns:[…], tier, collapse_dir[x,y], hint}],
  fracture_stages: [{stage: 1..3, floors:[…], sections:[tier…]}]
}
```
- `strength` — несущая способность колонны (т). `mass` — масса этажа/яруса (т). `com` — центр масс яруса.
- `holds` (только эстакада) — индексы пролётов, которые держит колонна опоры.
- `fracture_stages`: стадия 1 отделяется первой (ярус слабой линии), затем 2 и 3; этажи не повторяются.

**Упрощённая модель статики** (одна и та же в генераторе, в тестах и, при желании, в Unreal — `iv_worldgen/structure.py::simulate`):
1. Ярус устойчив, если уцелели ≥ 3 неколлинеарные колонны, **центр масс лежит внутри выпуклой оболочки уцелевших колонн с запасом 0,75 м**,
   и ни одна колонна не перегружена: нагрузка вышележащего пакета (`сумма mass` ярусов выше и этого) делится поровну между уцелевшими и
   не должна превышать `strength`.
2. Если ярус не держится, он и всё, что выше, падает (у эстакады — только упавшие пролёты). Направление падения — от ближайшей точки оболочки
   опор к центру масс.
3. Нижний ярус усилен (`strength` ×3,0 против ×1,8 у обычных колонн), поэтому потеря одной колонны здание целиком не роняет. Колонны линии слабости
   («передаточные», ×2,4) держат консольную часть: если убрать **все** колонны из `weak_lines[i].columns`, ярус и всё выше падает в `collapse_dir` (проверено
   тестами: отклонение < 25°, на практике < 1°).

## `infrastructure`
- `port`: `quay` (полигон причала), `containers[{id,pos,yaw_deg,levels,variant}]`, `cranes[hero id]`.
- `substation`: `yard` (полигон), `power_station_id`, `transformers[{pos}]`.
- `metro`: одна линия под улицей — `points`, `width` 16 м, `floor_z` −14 м, `ceiling_thickness` 3 м; `weak_segments` — участки под перекрёстками с тонким
  перекрытием (0,9 м) — место обрушения улицы; `stations` (2).
- `overpass_id`: id постановочного здания-эстакады. `guardrails[{id, points[[x,y,z]…], height}]` — ограждения набережной, эстакады, причала.

## `props[]`
`{id, kind: car|tree|lamp|bench, pos[x,y,z], yaw_deg, variant}`. Автомобилей ≥ 600 (в `seed 1` около 950), деревьев ~600, фонарей ~560. Вне
footprint'ов зданий и вне воды.

## `pois[]`
`spawn_player` (в воде у берега, дно ≈ −13 м, взгляд на город), `spawn_enemy` (центр площади), `spawn_duel_a` / `spawn_duel_b` (на проспекте, ~210 м
друг от друга), `camera` ×6 (`look_at`, `fov_deg`) для кинематографа.

## `hazards[]`
`{id, kind, polygon, effect}`: `electrical` (вокруг электростанции), `flood` (низины), `metro_collapse` (слабые участки метро).

## Гарантии (проверяются `python -m unittest`)
Детерминизм (хэш), валидность по JSON Schema, отсутствие пересечений footprint'ов и выхода зданий на улицы, проходимость 35 м от `spawn_player` до
`spawn_enemy`, ровно 6 hero, уникальные id, статика (weak line → обрушение в `collapse_dir` ± 25°; одиночное удаление колонны не роняет здание).
