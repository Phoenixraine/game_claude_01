# audio/ — процедурный звук IMPACT VECTOR (TASK-005)

82 звука (WAV, 48 кГц, 16 бит), синтезированных кодом: `numpy` + `scipy`, без сэмплов и лицензий. Имя файла = ID события
(контракт для интеграции в Unreal). Всё детерминировано: генератор каждого звука сидируется от его ID
(`zlib.crc32`), поэтому пересборка с нуля даёт те же файлы (проверяется тестом).

## Запуск

```bash
pip install numpy scipy matplotlib        # matplotlib нужен только для спектрограмм
python audio/build_all.py                  # всё: WAV + manifest.json + спектрограммы (~90 с на 4 процессах)
python audio/build_all.py --only hit_      # только звуки, чей ID содержит подстроку
python audio/build_all.py --jobs 1 --no-spectrograms
python -m unittest discover -s audio/tests # тесты (~2 с по готовым файлам)
```

`audio/out/mus_contact_theme_loop.wav` (60 с, стерео = 11,5 МБ) **не коммитится** (правило CLAUDE.md: бинарники ≤ 5 МБ);
он в `audio/out/.gitignore`, `build_all.py` его пересобирает, тесты достраивают недостающие файлы сами.
Остальные 81 WAV лежат в репозитории (всего 55 МБ при лимите 120 МБ).

## Соглашения

- **Шины:** `sfx_ext` (3D, моно, обязателен радиус затухания), `sfx_cockpit` (стерео, 2D), `ambient`, `ui`, `music`.
  Ambient-петли и музыка — стерео.
- **Уровни:** одиночные звуки нормированы по пику −1,5 дБFS (UI −4…−6); петли — по RMS −20 дБFS (музыка −18), пик ≤ −1,5.
  Место звука в миксе задаёт `volume_db` из манифеста, а не нормировка файла.
- **Петли** бесшовные по построению: аддитивные слои складываются по кругу (хвост заворачивается на начало), реверберация
  считается на утроенной копии петли, шумовые слои — кросс-фейдом равной мощности (`make_loop`); частоты дронов подогнаны
  под целое число периодов. Тест проверяет скачок на стыке относительно обычного шага сигнала и непрерывность уровня.
- **Одиночные звуки** начинаются и заканчиваются в тишине (фейды, обрезка хвоста ниже −60 дБFS, лимит длительности из реестра).
- **Масса/размер:** тяжёлые звуки строятся от падающего по высоте синуса 25–75 Гц + субгармоника + низкочастотный шум и
  длинный хвост реверберации с быстро затухающими верхами; тест требует ≥ 25 % энергии в 25–120 Гц у шагов, тяжёлого удара,
  дальнего взрыва и отсечения.

## Интеграция (UE5)

- Импортировать WAV как есть; `loop: true` → `Looping` в Sound Wave; 3D-звуки: Attenuation Shape = Sphere, радиус =
  `attenuation_radius_m` (в метрах → ×100 в см), `volume_db` → Volume Multiplier. Вариации (`*_01..NN`) — Random node по `variation_group`.
- Слои удара (§24): события должны запускать `hit_metal_contact_*` и `hit_lowfreq_thump_*` одновременно, `hit_deform_*` с задержкой
  ≈ 0–30 мс, `hit_cockpit_rumble_*` + `hit_compensator_kick` на шине кабины, `hit_debris_delay_*` — после удара (в самих файлах
  уже есть пауза 0,15–0,35 с).
- `mech_weapon_charge_loop` крутить до пика заряда и закончить `mech_weapon_charge_peak` (сигнал готовности, §13).

## Что проверено, а что нет

Проверено автоматически (`audio/tests/`, 18 тестов): состав и поля манифеста, совпадение файлов и манифеста, формат
(48 кГц/16 бит/каналы), длительности в заявленных пределах, отсутствие клиппинга/NaN/тишины/DC, тишина на краях одиночных
звуков, бесшовность 12 петель, выравнивание уровней петель, низкочастотная энергия «массивных» звуков, различие вариаций,
побитовая воспроизводимость, суммарный размер ≤ 120 МБ.

**Не проверено: на слух.** Ни один звук не прослушан (у авторов-агентов нет слуха): оценка велась по спектрограммам,
огибающим и физической логике. Ниже — честная оценка слабых мест; их стоит прослушать первыми.

| Звук | Риск |
|---|---|
| `mech_joint_creak_*`, `cockpit_harness_creak`, `env_*` groan внутри обрушения | скрип сделан цепочкой импульсов через бегущий резонатор; может звучать как «жужжание/трещотка», а не как металл или кожа |
| `cockpit_breath_loop` | дыхание = шум через формантный фильтр с огибающей вдох/выдох; без реальной модуляции голоса вероятно звучит как «воздух из шланга» |
| `env_glass_shatter_big`, `cockpit_panel_burst` | осколки — затухающие синусоиды 2–9 кГц; возможен колокольчиковый, а не стеклянный оттенок |
| `mech_step_water_*` | пузыри — восходящие чирпы; «мультяшность» вероятна |
| `env_missile_incoming` | доплер задан как смещение полосы шума, свист слабый; впечатление пролёта приблизительное |
| `mus_contact_theme_loop` | «струнные» — пилы с ФНЧ и вибрато: холодно и ровно, но не как живой оркестр; аккордовая схема простая (Dm–B♭–Gm–Asus, по 15 с) |
| `env_siren_distant_loop` | гармонический синтез без реального горна/мотора; эхо от зданий — три отражения |
| UI | сознательно скромные, без стилизации; их, вероятно, придётся подгонять под финальный дизайн HUD |

Также не проверялось: поведение под настоящим движком (интерполяция петель в Unreal, нормировка в Wwise/MetaSounds),
идентичность файлов между разными версиями numpy/scipy (в рамках одной среды — идентична, версии: numpy 2.4.6, scipy 1.17.1).
