# Баланс абордажа (TASK-017, пересчитано с реальной мини-игрой TASK-018)

Все числа ниже получены командой (≈ 30 с, детерминированно: тот же сид — те же цифры):

```
cmake -S core -B build && cmake --build build
./build/ivsim --boarding --seeds 25 --markdown out.md
```

## Как устроен эксперимент

- Сторона A — «игрок»: фехтовальщик-ИИ (Counterpuncher / Normal) плюс **бот абордажа**; сторона B — враг: каждый из 6 архетипов × 3 сложности, 25 сидов на клетку (450 дуэлей на стратегию).
- Бот абордажа играет в мини-игру взлома профилем `HackBot` (`core/include/iv/HackBot.h`: perfect 0 мс / 0 %, good 183 мс / 3 %, average 266 мс / 10 %, poor 350 мс / 25 %) и отвечает на телеграф замаха так (`kBots` в `core/tools/ivsim.cpp`):

| Бот | Реакция на телеграф замаха | Пропускает замах целиком |
|---|---|---|
| perfect | 20 тиков | 0 % |
| good | 24 тика | 3 % |
| average | 36 тиков | 12 % |
| poor | 52 тика | 30 % |

- Сложность взлома = `HackGame::DifficultyFor(архетип, сложность ИИ, состояние плеча)`: база 1 / 3 / 6 (Easy / Normal / Hard) ± архетип (Counterpuncher, Grappler +1; Breaker, Gunner −1) − повреждение плеча.
- Политики: «никогда» (чистый фехтовальщик), «как только можно» (ограничен кулдауном 60 с / 75 с после неудачи), «раз в 90 с» и «только когда безопасно» (враг далеко или сбит, стабильность ≥ 80, враг не в замахе).
- Пока пилот снаружи, мех на автопилоте (Counterpuncher/Easy, без атак) и получает урон ×1,4 (`kAutopilotDamageMult`); боты не нажимают ничего во время внешней вставки (бой заморожен).

Что подбиралось (всё в `core/include/iv/Tuning.h`, разделы «boarding» и «hack»):
- `kAutopilotDamageMult` 1,4 и слабый автопилот (Easy): при 1,35 + прежней заглушке-мини-игре идеальный бот выигрывал у фехтовальщика — абордаж был доминирующим; при 1,8 даже «безопасный» абордаж хорошего бота давал 64 % против 80 %;
- кулдаун 60 с (75 с после неудачи) вместо минимальных 45 с;
- шансы замаха `kSwatChance` 5/9/14 % за проверку раз в 0,5 с × множитель архетипа (Gunner 0,5, Grappler 1,4); окно `kSwingWindowTicks` 0,7 с и «мёртвая зона» 0,15 с;
- база сложности взлома 1/3/6 (после калибровки таблицы `kHackLevels`, см. `docs/ux/hack_calibration.md`).

## Ограничения (честно)

- Боты — простые модели (задержка + случайные нажатия), а не живые игроки; реальный успех зависит от экрана мини-игры и управления, это проверяется только в игре.
- Бот-фехтовальщик очень силён (80 % побед против ИИ), поэтому любое отсутствие пилота выглядит «убыточным»: для среднего игрока абордаж должен быть выгоднее. Если локальные тесты покажут, что абордаж никому не нужен, ослаблять надо `kAutopilotDamageMult` и кулдаун.
- Враг в симуляции не выбирает цель по положению пилота — замахи решаются по таймеру и вероятности (`kSwatChance`), как заложено в ТЗ.
- Баланс «враг тоже абордажит игрока» не считался: `tune::kAiBoardingEnabled = false`.
