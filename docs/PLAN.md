# IMPACT VECTOR — план работ (вертикальный срез)

Цель: играбельный срез на **Unreal Engine 5** по разделу 26 питча: один мех BASTION-01 + перекрашенный противник,
кабина от первого лица, прибрежный район (берег, улицы, башня, эстакада, вода, подстанция, 4–6 разрушаемых зданий),
бой по системе Combat Vector, функциональные повреждения (9 зон, отрыв руки), одно заряжаемое орудие, соло против ИИ,
локальная дуэль в split-screen. Кооператив «One Frame» и Survival — после среза.

## Принцип
Проект Unreal собирается **кодом** (C++ + Python-скрипты редактора + данные в JSON/CSV): уровень и город генерируются из
данных, мехи и звуки приходят готовыми файлами. Так результат воспроизводим, проверяем из командной строки
(`UnrealEditor-Cmd`, скриншоты, автотесты) и пригоден для параллельной работы нескольких исполнителей.

## Что делаю локально (по этапам §26)
1. **Установка и каркас:** UE 5.x, проект `ImpactVector`, модуль C++, сборка из консоли, скриншот-пайплайн.
2. **Combat Lab:** подключение `core/`, серые мехи, управление геймпадом/клавиатурой, ощущение массы.
3. **Structural Damage:** зоны в мехе, отрыв руки, изменение движений.
4. **Cockpit:** первый вид, тело пилота, «прозрачные стены», HUD в мире, инерция кабины.
5. **City Slice:** район из `worldgen/`, вода, дождь, подстанция, Chaos-разрушение 4–6 зданий.
6. **Local Duel:** split-screen, 60 FPS-профиль.
7. **Полировка:** звук, VFX (Niagara), меню в ангаре, финальная приёмка по референсам.

## Правила совместной работы
- Каждая облачная задача — своя ветка `claude/task-NNN-...` и Pull Request. Локально я забираю ветку, **сам** собираю и
  запускаю тесты, затем сливаю.
- Контракты между исполнителями (имена костей, события, форматы JSON) фиксируются в самих задачах — их не менять без записи в PR.
- Большие бинарники (FBX/WAV/PNG) — только итоговые, не больше 20 МБ на файл; всё, что генерируется скриптом, воспроизводимо.
