# IMPACT VECTOR — пакет питча и визуального направления

В архиве находятся материалы, собранные для предварительной разработки игры про гигантских мехов.

## Структура

### `01_visual_references/`
Семь сгенерированных кадров, задающих визуальное направление:

1. `01_key_art_mech_in_city.png` — внешний ключевой кадр меха в разрушенном городе.
2. `02_cockpit_city_view.png` — чистый вид из кабины на город.
3. `03_combat_hud_enemy_attack.png` — игровой бой и считывание направления атаки.
4. `04_damaged_cockpit.png` — повреждённая кабина, аварии и локальный HUD.
5. `05_hangar_main_menu.png` — ремонтный ангар и направление главного меню.
6. `06_local_split_screen_duel.png` — локальная дуэль с вертикальным split-screen.
7. `07_survival_mode_port_battle.png` — режим выживания в портовом районе.

Все изображения: PNG, 1672×941, 16:9.

### `02_pitch/`
- `IMPACT_VECTOR_FULL_PITCH_RU.md` — полный питч: центральная механика, управление, бой, режимы, интерфейс, разрушения, Unreal Engine, вертикальный срез, риски и визуальная библия.

### `03_prompts/`
- `VISUAL_REFERENCE_PROMPTS_RU.md` — отдельная подборка промтов для дальнейшей генерации изображений.

## Рекомендуемый порядок просмотра

1. Открыть `01_key_art_mech_in_city.png`.
2. Посмотреть четыре кадра кабины и геймплея.
3. Посмотреть split-screen и survival.
4. Прочитать разделы 1–15 полного питча.
5. Перейти к разделу 26 «Вертикальный срез» перед началом разработки.

## Важная производственная установка

Высокая визуальная планка является целью финального вертикального среза, но первый прототип должен проверять бой на серых моделях. Критические системы для доказательства концепции:

- формирование направления и цели удара;
- чтение замаха;
- блок, парирование и перехват;
- вклад положения ног и корпуса;
- функциональное повреждение конечностей;
- ощущение массы без искусственной задержки управления.
