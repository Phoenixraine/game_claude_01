# Мини-игра взлома люка — спецификация экрана (TASK-018)

Когда: пилот сел на плечо врага у люка (`BoardPhase::Hacking`, события `HackStarted` … `HackResultEvt`). Экран — **на весь кадр**, 16:9 (макеты 1920 × 1080), поверх замороженной внешней камеры; бой в это время продолжается (мех на автопилоте), поэтому в углу остаётся «камера врага».
Логика — `core/include/iv/HackGame.h` (всё правила и числа там; экран только рисует и шлёт `HackInput`). Данные — `data/hack/` (`difficulty.json`, `hack_levels.json`, `palette.json`, `schema.json`, `mockups/`).

## Как играется (3 слоя в одной сессии)

Порядок этапов по сложности (таблица `kHackLevels`): 1–7 — **Путь → Ритм → Частота**; 8–10 — то же + **фаза-босс** (Ритм + Частота под постоянной тревогой, быстрее и уже). Индикатор этапов — слева колонкой (кружки 1…5, пройденные залиты).

| Слой | Что делает игрок | Ввод (клавиатура / геймпад) | Ошибка |
|---|---|---|---|
| **Путь** | провести цепочку узлов от входа (слева) к ядру (справа), не пересекая себя; ключи **1…4** брать строго по порядку; шестиугольник с крестом — блокер; ромб с крестом — лёд: заходя на него, пилот проскальзывает дальше в том же направлении | стрелки / WASD / стик или D-pad — шаг; `Z` / `B` — шаг назад (−0,2 с) | шаг в блокер, в пройденный узел, не в тот ключ, в ядро без всех ключей |
| **Ритм** | 3–5 дорожек (← ↓ ↑ → и 5-я `Пробел`/`A`): жать дорожку, когда импульс на линии (окно ± `hitWindow` тиков, в тревогу на 1 меньше) | стрелки / WASD (дорожки), `Пробел` / `A` (5-я) | нажатие без импульса в окне; импульс прошёл линию |
| **Частота** | кольцо: сектор взломщика (белая игла) вращается против окна ЛЬДА (красная дуга); нажать `Пробел` / `A`, когда игла внутри дуги; каждый удачный захват **сужает окно** и разгоняет сектора | `Пробел` / `A` | захват мимо окна: ошибка и шаг назад по замкам (окно снова шире) |

**Температура ЛЬДА** (шкала вверху, красная черта = порог тревоги 70 %): каждая ошибка добавляет нагрев (`heatPerMistake`) и **отнимает время** (`penaltyMs`); нагрев остывает 6 пунктов в секунду. На пороге **тревога** (надпись, красная рамка): окно ритма уже на 1 тик, сектора частоты быстрее на 12 %.
При 100 % **ЛЁД срабатывает**: текущий этап начинается заново (та же раскладка), штраф времени ×3, нагрев падает до 40 % — это **штраф, а не мгновенное поражение**. Общий **лимит времени** 25–60 с (полоса вверху слева с засечками-секундами; последняя четверть — красная).
Победа — все этапы пройдены до конца таймера; `quality` (0…1: оставшееся время, ошибки, срабатывания ЛЬДА) задаёт силу гранаты. Выход `Esc` / `B` — провал (пилот возвращается по крюку).

## Раскладка 16:9 (макеты — `data/hack/mockups/*.svg|png`)

| Зона | Положение (px при 1920 × 1080) | Содержимое |
|---|---|---|
| рамка | отступ 40, угловые скобки | тонкие светящиеся линии (DESIGN_BIBLE §5), без «карточек» |
| таймер | x 80–840, y 118–156 | полоса с засечками-секундами, подпись «ВРЕМЯ» |
| ЛЁД | x 920–1340, y 118–164 | шкала нагрева, красная отметка 70 %, надпись «ТРЕВОГА» справа при тревоге |
| камера врага | x 1480–1840, y 80–283 | **занято под PiP из TASK-017**: при `BoardingSwatTelegraph` показывает замах руки врага, рамка мигает красным, полоса `ticksToImpact` под ней; кнопка **«перелёт»** (`swing`) подсвечивается в окне, когда её можно нажимать |
| этапы | x 40–400, y 230–630 | колонка кружков 1…5 + названия |
| рабочая область | центр, x 560–1700, y 290–900 | слой текущего этапа |
| подсказки | x 300–1620, y 930–1000 | клавиши KBM и пад |

Без читаемых английских слов; весь текст — короткие русские метки капсом («ПУТЬ», «РИТМ», «ЧАСТОТА», «ВРЕМЯ», «ЛЁД», «ТРЕВОГА»), числа — цифры; фон — тёмное стекло (`#06111a`) с развёрткой, палитра — `data/hack/palette.json`.
Состояние **никогда не передаётся только цветом**: блокеры — шестиугольник с крестом, лёд — ромб с крестом, ключи — с цифрой, ошибка — ещё и тряска и звук.

## Анимации и звук

| Событие | Анимация | Звук (`HackSfx` → имя для audio/) |
|---|---|---|
| появление экрана | рамка «собирается» из углов за 0,35 с, шкалы заполняются | — |
| шаг по пути | узел загорается, линия дорисовывается за 80 мс | `Tick` → `hack_tick` |
| удачный ход / импульс / замок | белая вспышка 120 мс, кольцо расходится | `Ok` → `hack_ok` |
| ошибка | красная вспышка 0,25 с, лёгкая тряска (амплитуда 6 px), «−1,5 с» всплывает у таймера | `Err` → `hack_err` |
| тревога | красная пульсация рамки (1 Гц), полоса ЛЬДА мигает | `Alarm` → `hack_alarm` |
| срабатывание ЛЬДА | экран «трескается» на 0,3 с, этап перезапускается | `IceTrip` → `hack_alarm` (двойной) |
| этап пройден | кружок этапа заливается, линия к следующему тянется | `StageClear` → `hack_stage_clear` |
| успех | все кружки загораются, люк на заднем плане «раскрывается», 0,6 с затем экран гаснет | `Success` → `hack_success` |
| провал / таймаут | экран гаснет «в помехи» 0,4 с | `Fail` → `hack_fail` |

`HackGame::DrainSfx()` возвращает накопленные за тик кадры звука; согласовать имена с `audio/` (в `audio/` аналогов пока нет — добавлять 6 звуков `hack_*`).

## Поведение

- **Пауза / потеря фокуса**: ядро идёт только пока вызывают `Step`; экран на паузе просто не вызывает `HackGame::Step` (и `Boarding::Step` — бой стоит). Вход на паузе игнорируется, при возврате — 1 с обратного отсчёта без потери времени.
- **Шок** (мех получил удар, пока пилот на люке): `Boarding` отнимает у таймера ≈ 0,8 с (`AddPenalty`), на экране — тряска и надпись «−0,8 с».
- **Перелёт на другое плечо** (`BoardingSwingOk`): экран на 0,9 с затемняется, затем возвращается с **новой раскладкой** (`HackGame::Reroll(0.5)`: сохраняется половина пройденных этапов, нагрев сбрасывается).
- **Геймпад и клавиатура — равноправны**: всё достижимо 4 направлениями + 2 кнопками (`confirm`, `aux`/назад) без курсора. Подсказки внизу переключаются по последнему использованному устройству.
- Доступность: масштаб интерфейса 100–150 %, режим «без тряски», режим «удлинить окна» (множитель к `hitWindow`/`lockHalfDeg` — в игровом слое, ядро не меняется).

## Подключение в Unreal

1. Игровой цикл: `HackInput` собирается из Enhanced Input (одно нажатие = один тик ребра), `Boarding::Step(duel, BoardingInput{.hack = …})` пробрасывает его в `HackGame`.
2. Экран читает `Boarding::hack()`: `stage()`, `stageIndex()/stageCount()`, `progress()`, `ticksLeft()/timeLimit()`, `heat()`, `alarm()`; слой пути — `path()`, `pathX()/pathY()`, `pathVisited()`, `pathKeysTaken()`; ритм — `rhythm()`, `rhythmStatus(i)`, `rhythmWindow()`, `stageTick()`; частота — `freq()`, `hackerAngle()`, `iceAngle()`, `freqHalfWidth()`, `freqLocks()`.
3. Готовые раскладки без порта генератора: `data/hack/hack_levels.json` (500 сессий, схема `schema.json`); проиграть такую раскладку в ядре — `HackGame::LoadLayout(...)`. Источник истины остаётся ядро: тест `Hack.PregeneratedSessionsEqualTheGenerator` сравнивает файл с генератором побайтно.
4. Макеты нарисованы кодом: `python3 data/hack/make_mockups.py` (раскладки берутся из `hack_levels.json`, уровень 6).
