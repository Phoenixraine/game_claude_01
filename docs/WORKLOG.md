Free-look (Z / Alt / Back): пригнуть голову и увидеть своё тело.

- **Производительность (кабина):** мониторы переведены с 8 render target на один атлас 1024×1152, геометрия мониторов растеризуется на CPU (`FIVMonCanvas` в `IVCockpit.cpp`), в Canvas остаётся только текст. Линии/треугольники Canvas стоили ~100 мс render thread — было 22 fps, стало 65–70 fps. В лог каждые 10 с пишется `IV perf: ... game/render/gpu ms`.
- **Меню:** новое (`AIVHUD::DrawMenu`): заголовок с хроматическим сдвигом и редким глитчем, плавная подсветка пункта, значения справа, панель описания режима, подсказки клавиш.

Куски броня отлетают при сильных ударах и при смене состояния зоны, здания разлетаются осколками при подрыве.
- **Вертолёты:** `IVHelicopter.*` — процедурная модель, прожектор (spot + объёмный свет), навигационные огни, звук ротора (`Scripts/make_heli_sound.py`).
