## Сделано
- **Город/свет:** `Scripts/make_arena.py` генерирует арену «Такэсита» (district_arena.json: башни со стеклом, мега-вывески, огни, нити фонарей); материалы `M_GlassTower`, `M_NeonSign` (процедурные псевдо-кандзи), `M_Trim`; `IVDistrictDecor.cpp` (короны башен, LED-полосы, вывески, point-light с объёмным рассеянием); светлее экспозиция/туман.
- **Кабина v3:** `art/cockpit/v3/build_cockpit_v3.py` — комната с граненым стеклянным куполом, консоли, стены, люк, потолок, платформа, тело пилота (5 частей), рука-рига; layout JSON (трубы, провода, мониторы, лампы, сокеты). `IVCockpit.cpp` — динамика: трубы (рвутся, пар), провода (верле, рвутся), мониторы (render target через Canvas), частицы пара/искр/огня, сигнализация, тело пилота шагает. Free-look (Z / Alt / Back): пригнуть голову и увидеть своё тело.
- Отладочные опции: `-IVCam=6 -IVFreeCams="x,y,z,pitch,yaw|..." -IVFreeDur=3`, `-IVLook=pitch,yaw`, `-IVCkFailAt=сек`, `Scripts/shot.ps1`, `Scripts/mats.ps1 -Only ...`, `Scripts/cockpit_sync.ps1`.

- **Производительность (кабина):** мониторы переведены с 8 render target на один атлас 1024×1152, геометрия мониторов растеризуется на CPU (`FIVMonCanvas` в `IVCockpit.cpp`), в Canvas остаётся только текст. Линии/треугольники Canvas стоили ~100 мс render thread — было 22 fps, стало 65–70 fps. В лог каждые 10 с пишется `IV perf: ... game/render/gpu ms`.
- **Меню:** новое (`AIVHUD::DrawMenu`): заголовок с хроматическим сдвигом и редким глитчем, плавная подсветка пункта, значения справа, панель описания режима, подсказки клавиш.
- **Мех:** корпус светлее и металличнее (краска ×2.1, metallic 0.62+, roughness 0.2–0.34), френелевая подсветка по краю в цвет акцента.
- **Обломки:** библиотека осколков из TASK-016 импортирована в `/Game/Shards` (178 мешей, `Scripts/import_shards.py`). `AIVFXManager::SpawnChunks` — летящие горящие куски (бетон, плиты, стекло, сталь, броня, галька) с баллистикой, отскоком, огнём/дымом по пути; материал `M_Chunk` (раскалённые трещины остывают). Куски броня отлетают при сильных ударах и при смене состояния зоны, здания разлетаются осколками при подрыве.
- **Вертолёты:** `IVHelicopter.*` — процедурная модель, прожектор (spot + объёмный свет), навигационные огни, звук ротора (`Scripts/make_heli_sound.py`). Кружат над ареной, периодически снижаются («низкий пролёт»); в это время F (Scoop) хватает вертолёт и швыряет врагу: горящий полёт, взрыв, ослепление. HUD меняет подпись кольца на «ВЕРТОЛЁТ».
- **Заражённый враг:** `AIVMechPawn::BuildGrowths` — 42 нароста (шипы, опухоли) на костях врага, материал `M_Growth` с пульсирующими жилами; растут по мере разрушения зон.
- **Кабина:** тело пилота читается при взгляде вниз (светлее костюм/пластины, подсветка снизу, подсветка воротника). Монитор-шейдер совместим с DXR (SampleLevel).
- **Обучение:** добавлены шаги про рывок-удар, прыжок/удар сверху/подкат, сцепку клинков, берсерк, аварию отсека, вертолёты.
- **RTX:** `r.RayTracing=True` в DefaultEngine.ini (пресет «RTX» включает аппаратный Lumen/отражения; ошибка компиляции M_Monitor в hit-шейдерах исправлена). Визуальная разница небольшая, fps тот же (RTX 3090).

## Сессия 4 (ночь 4–5 октября): список «обязательно» владельца
- **Уклонение:** поворот всего тела вокруг вертикальной оси (рысканье таза), корпус вертикален, нога отставлена, мех скользит в сторону-назад; контратаки после уклонения нет (ядро, тест `Dodge.EvadingALateralSlashDoesNotOpenACounterWindow`).
- **Траектория замаха:** сглаженная лента (Catmull-Rom) со стрелкой на конце, красная — удар, зелёная — блок.
- **Окно парирования:** ядро считает `contactTicks` (тиков до контакта); HUD рисует сжимающееся кольцо и «БЛОК СЕЙЧАС!»; для рывка/удара сверху/захвата — отдельные подсказки (прыжок, подкат, парирование). Успешное парирование: левая рука поднимается, залп ракет (`FireParryRockets`).
- **Одна рука:** при замахах мечом левая рука остаётся в гарде. **Клинок из руки:** новая модель `art/arm_blade` (наруч + клинок), `SM_ArmBlade`.
- **Искры:** при касании клинок-клинок и клинок-тело — крупные искры, вспышка света, лязг.
- **Дождь:** экранный слой тонких частых капель (`M_RainPP`, постпроцесс, не рисуется на кабине) + редкие тонкие капли в мире; падают вниз.
- **Земля:** улицы красятся в материале по мировым координатам (разметка, зебры, бордюры, тротуары, люки); убран «песочный» оттенок. ~1500 пропсов: пробки, такси, автобусы, лотки, пешеходы с зонтами, фонари, киоски, стройплощадка.
- **Туман:** плотнее вдали и у земли (второй слой), тёмное объёмное альбедо — без молочной дымки. **Шторм:** молнии (вспышка луны/неба/экспозиции), гром, дальние взрывы (`-IVNoStorm`, `-IVStormNow` для тестов).
- Не сделано: DLSS/FSR (плагинов нет в UE 5.8 и без Fab-входа их не скачать — есть TSR и масштаб рендера), разрушаемость корпуса, дальнейшая детализация кабины.
