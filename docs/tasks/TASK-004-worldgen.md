# TASK-004 — Генератор прибрежного района (`worldgen/`, Python)

**Ветка:** `claude/task-004-worldgen` → PR в `main`. **Область:** только `worldgen/`.
**Источник:** питч §17 «Город как оружие», §18 «Разрушаемость», §26 этап 4 «City Slice», §29 «Референс 1, 8».

## Цель
Детерминированный генератор района города (Python 3.10+, только стандартная библиотека + при желании `numpy`), который по сиду выдаёт
`district.json` — полное описание арены для Unreal. Unreal-сторона (я) создаёт по нему акторы, поэтому формат — контракт.
Арена: ≈ 1.6 × 1.2 км, мех 82 м ростом. Масштаб: улицы шириной 40–90 м (иначе мехам не развернуться), кварталы 120–250 м.

## Содержимое района
- **Рельеф и вода:** береговая линия (выход меха из моря — отлогий спуск 0…−25 м по оси X), набережная, мелководье, затапливаемые низины.
- **Улицы и кварталы:** сетка с искажением (не идеальная), 2 проспекта, 1 площадь, 1 тупик/узкая улица (для «загнать в узкую улицу», §3), перекрёстки.
- **Здания (обычные)** `type: "generic"`: footprint-полигон, высота 30–220 м, этажность, тип (office, residential, industrial, parking), стиль фасада.
- **Постановочные здания** `type: "hero"` (ровно 6): `glass_tower` (220 м), `stadium`, `residential_complex`, `overpass` (эстакада 400 м),
  `port_crane`, `power_station`. У каждого — подробный **граф конструкции** (см. ниже).
- **Инфраструктура:** мост/эстакада, порт с контейнерами, краны, подстанция (зона электроопасности), метро (одна линия: тоннель под улицей, участки с «слабым перекрытием»), деревья, автомобили (в сумме ≥ 600 точек), фонари, дорожные ограждения.
- **Точки интереса:** `spawn_player` (в воде у берега), `spawn_enemy` (на площади/между зданиями), `spawn_duel_a/b`, камеры для кинематографа.

## Граф конструкции здания (для разрушения, §18 Уровень 2–3)
Для каждого `hero`-здания и ≥ 25% обычных: `structure`: 
- `columns`: список опор `{id, pos[x,y,z], height, strength}`; `floors`: перекрытия `{id, z, supports:[column ids], mass}`;
- `weak_lines`: линии структурного напряжения `{id, columns:[...], collapse_dir:[x,y], hint}` (направление падения, §17 «Обрушение здания»);
- `fracture_stages`: 3 стадии разрушения (список этажей/секций, которые отделяются на каждой).
Генератор сам проверяет статику: если убрать колонны из `weak_lines[i]`, симуляция упрощённой модели (граф опор + нагрузки) даёт обрушение
в `collapse_dir` ± 25°; если убрать любую одну случайную колонну — здание не должно целиком падать (стоят «усиленные нижние этажи», §17).

## Формат `district.json` (контракт; версия `schema_version: 1`)
Единицы — метры, ось X вправо, Y вперёд (на город от моря), Z вверх. Корень: `{seed, schema_version, bounds, terrain, water, roads, blocks,
buildings, infrastructure, props, pois, hazards}`. Полная схема — в `worldgen/SCHEMA.md` (написать) и `worldgen/schema.json` (JSON Schema).
`terrain` — heightmap `r16` 1009×1009 (`worldgen/out/heightmap.r16` + метаданные), совместимо с Unreal Landscape.

## Выходные файлы и проверка
`worldgen/generate.py --seed N --out worldgen/out/`, `district.json`, `heightmap.r16`, `preview_topdown.png` (карта сверху с легендой),
`preview_skyline.png` (силуэт со стороны моря), `SCHEMA.md`, `README.md`, тесты `worldgen/tests/` (`python -m unittest`).
Тесты: детерминизм (двойной прогон — одинаковый хэш), валидность по JSON Schema, нет пересечений footprint'ов, проходимость
(от `spawn_player` до `spawn_enemy` есть путь шириной ≥ 35 м), ровно 6 hero-зданий, статика (см. выше), все id уникальны.
В PR — реальные команды, результаты, превью, что не проверено.
