# TASK-007 — Процедурная анимация меха: библиотека поз и циклов (`anim/`, Python)

**Ветка:** `claude/task-007-animation` → PR в `main`. **Область:** только `anim/`.
**Источник:** питч §5.2 (замахи), §5.4 (экономика позы), §6 (блок, уклонение), §11 (масса и движение), §14 (повреждённые конечности).

## Цель
Анимация меха в игре — **процедурная**: поза = набор углов суставов, между позами — кривые времени. Нужна библиотека данных и математики
(Python 3.10+, `numpy` разрешён), которую я перенесу в Unreal. Скелет — контракт из TASK-002: кости `root, pelvis, torso, head,
shoulder_{l,r}, upperarm_{l,r}, forearm_{l,r}, hand_{l,r}, thigh_{l,r}, shin_{l,r}, foot_{l,r}, reactor`. Рост меха 82 м, вес >8000 т:
всё медленно и тяжело, **начало движения видно сразу** (перенос веса, поворот таза), завершение — долго (питч §11).

## Что сделать
1. **Кинематика:** `anim/rig.py` — иерархия, длины костей (параметры), оси вращения и пределы суставов в градусах (реалистичные для гидравлики:
   плечо 3 DoF, локоть 1 DoF 0…140°, кисть 2 DoF, бедро 3 DoF, колено 1 DoF 0…120°, стопа 2 DoF, торс 3 DoF ограниченно, голова 2 DoF), прямая кинематика и
   двухзвенная IK (нога и рука) с проверкой пределов.
2. **Позы** (`anim/data/poses.json`): стойка по умолчанию (`guard_neutral`), 8 замахов (верх/право/лево/низ × правая/левая рука) в трёх фазах каждый —
   `windup`, `commit`, `strike_end` (+ `recovery`), быстрые удары (поршень, боковой, толчок предплечьем, ладонь), блоки по 4 секторам, усиленная стойка,
   уклонение влево/вправо/назад (один тяжёлый шаг), захват, таран, зарядка орудия (плечо раскрыто, ноги зафиксированы), падение на колено, опрокидывание.
   Для каждой позы: углы суставов + положение центра масс + положение опорных точек стоп.
3. **Движение:** `anim/locomotion.py` — генератор шагового цикла для ходьбы/бега/поворота на месте/остановки с переносом веса (фазы: weight shift → lift → swing → plant),
   параметры скорости; без скольжения стоп (тест: скорость опорной стопы относительно земли < порога на фазе опоры). Таблица «длина шага/частота» для 82-метровой машины
   (не бегать, как человек: шаг ≈ 18–26 м, период 3.0–4.5 с на ходьбе).
4. **Кривые:** `anim/curves.py` — easing-функции (с запаздыванием «тяжести»: быстрый старт намерения + медленное завершение), блендинг поз с независимыми
   таймингами на сустав, вторичное движение (инерция кабины/плеч — пружина-демпфер) и «камера-тряска от шага» (амплитуда по фазе).
5. **Повреждения:** модификаторы поз при повреждении зоны (хромота: асимметрия шага, повисшая рука, заклиненный сустав) — функция
   `apply_damage(pose, damage_state)`, согласованная с зонами TASK-001 (`Head, Torso, Reactor, ShoulderL/R, ArmL/R, LegL/R`; состояния
   `Intact, Dented, Exposed, Damaged, Critical, Destroyed, Severed`).
6. **Экспорт:** `anim/export.py` → `anim/out/poses.json`, `anim/out/locomotion.json`, `anim/out/curves.json` (+ схема), а также `anim/out/*.bvh` для 6 ключевых
   клипов (ходьба, замах-верх-право, блок, уклонение, падение, удар) — для просмотра в любом DCC. Опционально — Blender-скрипт `anim/blender_preview.py`,
   рендерящий превью-гифки/кадры поз на каркасной болванке (если `bpy` доступен).
7. **Визуализация:** `anim/preview.py` рисует кадры (matplotlib, если есть; иначе простой растр через numpy+PNG) силуэтов поз спереди/сбоку — **смотрите** на них и
   исправляйте нереалистичные позы.

## Приёмка
`python -m unittest discover -s anim/tests` — зелёные: пределы суставов соблюдены во всех позах, IK достигает цели или честно сообщает недостижимость, нет скольжения стоп,
детерминизм, поза после удара совместима с таблицей переходов (`recovery` ведёт в допустимую пару поз), асимметрия при повреждении ноги заметна (> порога).
В PR: реальные команды и результаты, примеры кадров, что слабо.
