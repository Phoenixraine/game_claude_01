# TASK-014 — Музыка в духе Mecha BREAK: математический синтез (`music/`, Python)

**Ветка:** `claude/task-014-music` → PR в `main`. **Область:** только `music/`. **Направление:** `docs/art/DESIGN_BIBLE.md` п.5. Звуковые эффекты (`audio/`, TASK-005) не менять.

## Цель
Набор музыкальных композиций, полностью **синтезированных кодом** (Python 3.10+, `numpy`, при желании `scipy`; никаких внешних сэмплов/лицензий), в жанре тяжёлой электронно-оркестровой экшн-музыки про мехов:
синтезированные «живые» ударные, тайко, дрожащие и грязные басы (saw/supersaw + sub, sidechain-«дыхание»), арпеджиаторы, оркестровые струнные (ансамбль пилообразных/аддитивных голосов с вибрато и атакой), медные акценты и «хиты» (brass stab),
хоровые пэды (формантные фильтры), синтезированные электрогитарные рифы (карплус-стронг + дисторшн + кабинет-фильтр), риз-нарастания, импакты, риверсы, свипы. Звук должен быть мощным, широким, без цифрового клиппинга. Основной темп 120–150 BPM.

## Что сделать
Модули `music/gen/`: `theory.py` (шкалы, аккорды, прогрессии, ритмические паттерны, секвенсер с «человеческим» сдвигом и динамикой), `synth.py` (осцилляторы с полосным ограничением, ADSR, фильтры SVF/biquad, дисторшн, хорус, реверб
(FDN или свёрточный на сгенерированном IR), компрессор, лимитер, сайдчейн), `drums.py`, `bass.py`, `strings.py`, `brass.py`, `choir.py`, `guitar.py`, `fx.py`, `mix.py` (стерео-микс, мастеринг: -14 LUFS-ориентир, пик ≤ -1 dBFS).

**Треки (WAV 48 кГц, 16 бит стерео) — каждый в виде полного микса и отдельных стемов** (`drums, bass, harmony, lead, fx`) одинаковой длины и с общей сеткой тактов, чтобы игра могла смешивать слои:
1. `mus_main_menu` — 90–100 BPM, атмосферный ангар: низкий пульс, металлическая перкуссия, медленные струнные, надежда и тяжесть (бесшовная петля 90–120 с).
2. `mus_exploration` — 100 BPM, напряжённая подготовка перед контактом: пульс баса, тихие импакты (петля 80–120 с).
3. `mus_combat_a` — 135 BPM, a-moll/d-moll, главная боевая тема: тайко+электро-барабаны, синт-бас, рифы, струнный ostinato, медные акценты (петля 120–180 с, 4 интенсивности через стемы).
4. `mus_combat_b` — 128 BPM, вторая боевая тема (другая тональность, другой рифф), для разнообразия.
5. `mus_critical` — 150 BPM, критический момент боя (низкое здоровье/перегрев): ускоренный пульс, диссонансы, сирено-подобные свипы (петля 40–60 с).
6. `mus_ultimate` — 140 BPM, 25–40 с: нарастание → драматичный дроп на момент ультимейта (одиночный, не петля).
7. `mus_victory` — 15–25 с, героический финал; `mus_defeat` — 15–20 с, угрюмый, низкие струнные и затухающий пульс.
8. `mus_results` — 100 BPM, спокойная петля 60–90 с для экрана результатов; `mus_tutorial` — 105 BPM, нейтральная, не отвлекающая (петля 60–90 с).
9. Коротко-стингеры: `sting_contact`, `sting_limb_lost`, `sting_building_collapse`, `sting_kill`, `sting_warning` (1–5 с).
Разные темы должны использовать **общее мотивное ядро** (3–4 ноты), поданное в разных ритмах и ладах — чтобы музыка «звучала как одна игра».

## Контроль качества (вы не слышите — используйте математику и смотрите на картинки)
Для каждого трека: спектрограмма (`music/out/spectrograms/*.png`), график огибающей громкости, проверка: нет клиппинга, DC-смещения, щелчков на границах петель (стык первого/последнего сэмпла и производной), корректное совпадение длины стемов,
тональность и темп соответствуют заявленным (оценить по автокорреляции огибающей/хроматограмме — тестом), стереоширина (коррелированность L/R в допустимых пределах), диапазон громкости (LUFS-приближение) и динамика (кресты нарастаний). Манифест
`music/manifest.json` (id, файл, BPM, тональность, длительность, loop, стемы, точки перехода по тактам, intensity-слои). `music/README.md`: как запустить, как добавлять треки. Тесты `music/tests/` (минимум 15 проверок). `python music/build_all.py` с нуля.
Файлы > 20 МБ в git не класть — генерировать скриптом (в git: манифест, спектрограммы, небольшие WAV ≤ 20 МБ либо MP3/OGG если есть кодек; иначе положите только короткие превью-фрагменты по 30 с).
