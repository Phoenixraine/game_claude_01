# TASK-011 — Ангар для главного меню и экрана результатов (Blender, скрипты) `art/hangar/`

**Ветка:** `claude/task-011-hangar` → PR в `main`. **Область:** только `art/hangar/`.
**Источник:** питч §22 п.1, §29 «Референс 12», изображение `docs/pitch/01_visual_references/05_hangar_main_menu.png`. Окружение Blender — как в TASK-002 (`bpy`, при невозможности запуска — честно «не запускалось»).

## Цель
Сцена-ангар, в котором стоит BASTION-01 в док-станции, а игрок смотрит с ремонтной платформы на меха; слева — сервисный терминал (стекло с UI). Это **статическая интерьерная сцена с камерой** и
набором модулей: меню должно быть красивым и спокойным (светлый нейтрально-серый свет без желтизны), с ощущением масштаба (люди и машины у ног меха).

## Состав (имена — контракт)
- `Hangar_Shell`: огромный зал (≈ 160×100×70 м), ферменная крыша, световые панели, большие ворота, колонны, рельсы мостового крана, пол с разметкой и следами износа. Бюджет ≤ 400 тыс. треугольников.
- `Dock_Station`: тяжёлая сухая ремонтная док-станция под мех: порталы, гидравлические упоры, трубопроводы, кабельные жгуты, лесенки, платформы обслуживания на 3 уровнях (для рабочих).
- `Gantry_Crane` и `Service_Drone_*` (4 вида ремонтных машин: гусеничный погрузчик, подъёмник-ножницы, манипулятор, платформа с кабелем), `Worker_*` (низкополигональные силуэты рабочих в светоотражающих
  жилетах, 3 позы), ящики/контейнеры с инструментами, бочки, шланги, сварочные посты, стойка с бронепанелями (снятые панели меха).
- `Service_Terminal`: стеклянная панель-экран (плоскость с UV 0–1 и слотом `M_TerminalGlass`) в массивной раме, консоль, кресло-платформа игрока; позиция камеры меню — empty `Cam_Menu` с параметрами (FOV, высота глаз, взгляд на меха),
  дополнительные empties: `Cam_Hangar_Wide`, `Cam_Results_Replay`, `Light_Key`, `Light_Fill`, `Light_Rim`, `Light_Panel_NN` (позиции/рекомендованная мощность в `hangar_lights.json`).
- Материалы: `M_ConcreteFloor`, `M_SteelBeam`, `M_PaintedMetal`, `M_Rubber`, `M_SafetyOrange`, `M_ReflectiveVest`, `M_TerminalGlass`, `M_EmissivePanel`. UV без перекрытий.
- Масштабный набор для результатов боя: `Damage_Prop_*` — снятые повреждённые панели BASTION (6 видов) на поддонах (для экрана «ремонт после боя»).
