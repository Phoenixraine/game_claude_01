# TASK-003 — Кабина меха и тело пилота (Blender, скрипты)

**Ветка:** `claude/task-003-cockpit` → PR в `main`. **Область:** только `art/cockpit/`.
**Референсы:** `docs/pitch/01_visual_references/02_cockpit_city_view.png`, `03_combat_hud_enemy_attack.png`, `04_damaged_cockpit.png`;
питч §15 «Кабина как часть игрового процесса», §23 «Кабина», §29 «Референс 3, 7».

## Цель
Скрипт `art/cockpit/build_cockpit.py` (Blender 4.x, `bpy`, окружение — как в TASK-002) строит интерьер одноместной кабины от первого
лица и экспортирует для Unreal: **камера пилота на уровне глаз находится в точке (0,0,0)**, взгляд вдоль −Y, единицы — метры.
Не десятки декоративных экранов: крупные функциональные формы, сочетание подводной лодки, крана и истребителя (питч §23).

## Состав (контракт имён — не менять)
- `Cockpit_Frame`: несущий каркас, стойки, балки; `Seat`, `Harness_*` (ремни).
- Окно-обзор: **панели-сенсорные стены** отдельными объектами `ViewPanel_<Front|FrontL|FrontR|SideL|SideR|Top|FloorL|FloorR>`
  (каждая — плоскость/слегка изогнутая поверхность с UV 0–1 и собственным слотом материала `M_ViewPanel_<имя>`), чтобы в игре
  каждая панель могла быть то прозрачной, то непрозрачной (питч §15). Рядом — `ArmorShutter_<то же имя>`: непрозрачная бронепанель, закрывающая её.
- Управление: две рамы для рук `ControlFrame_L/R` с подвижными частями: `ControlGrip_L/R` (захват), шарнирные штанги `ControlArm_L/R_01..03`.
  Педальный узел `Pedals_L/R` + `FootRest`. У каждой подвижной части — ось и пределы вращения в `cockpit_rig.json`.
- Тело пилота (низкополигональный, но аккуратный, **без лица**, шлем): `Pilot_Arm_L/R` (плечо→предплечье→кисть, 3 кости), `Pilot_Leg_L/R`,
  `Pilot_Torso_Visible`, `Pilot_Helmet` (только отражения/края, для вида при взгляде вниз). Скелет `PilotRig` с костями
  `hand_l, lowerarm_l, upperarm_l` (и `_r`), `thigh_l, calf_l, foot_l` (и `_r`), `spine`, `head`; IK-цели `ik_hand_l/r`, `ik_foot_l/r`.
- Интерактивные узлы повреждений: `Damage_Panel_<Left|Right|Top|Front>_<01..03>` (панели, которые могут лопнуть/искрить),
  `CoolantPipe_<NN>` (трубки охлаждения с точками течи — пустые `Leak_<NN>`), `CableBundle_<NN>`, `Emitter_Spark_<NN>` (empties для искр),
  `Gauge_Mechanical_<NN>` (механические индикаторы), `Light_Status_<NN>` (empties для источников света).
- Материалы: `M_CockpitMetal`, `M_CockpitDark`, `M_Rubber`, `M_Suit`, `M_Glass`, `M_Emissive_White`, `M_Emissive_Blue`, `M_Emissive_Amber`,
  `M_ViewPanel_*`. Все с UV (без перекрытий), PBR.
- Бюджет ≤ 300 000 треугольников. Обязательны фаски, крепёж, швы, износ в геометрии (не только в текстуре).

## Выходные файлы
`art/cockpit/out/Cockpit.fbx` + `.glb`, `Pilot.fbx`, `cockpit_rig.json` (оси, пределы, имена), `cockpit_parts.json`,
превью `preview_eye_view.png` (вид из камеры пилота, 90° по вертикали ≈ как на референсе 02), `preview_wide.png`, `preview_damage_layout.png`,
`preview_pilot.png`, `README.md`.

## Приёмка
1. Скрипт запускается с нуля без интерактива, сам проверяет контракт (имена, UV, бюджет) и падает при нарушении.
2. `preview_eye_view.png` визуально сопоставим с референсом 02: рамы и руки внизу кадра, обзор впереди не загорожен, вид не «тоннельный».
3. Все объекты из контракта присутствуют; запись `cockpit_rig.json` согласована с геометрией (пределы углов не ломают меш).
4. Честный отчёт в PR: что запускалось, что видно на превью, что осталось слабым.

## ОБНОВЛЕНИЕ v2 (приоритетнее текста выше при расхождениях) — прочитать `docs/art/DESIGN_BIBLE.md` п.2
- Стиль — **боевая рубка (conn-pod) в духе «Тихоокеанского рубежа»**: каркас с гидро-амортизаторами, два ложемента-подвеса (игрок в левом, правый ложемент пуст/занят силуэтом второго пилота для кооператива), «риги»-рамы для рук и ног, брезентовые ремни, гнёзда перчаток, провода, трафареты без слов,
  оранжевые защитные скобы, тяжёлые тумблеры и рычаги, барабанные/ленточные индикаторы. Больше детали и износа, чем в простом наброске (бюджет ≤ 600 000 треугольников), **PBR-текстуры 2048²** (BaseColor/Normal/ORM/Emissive) с износом по кривизне и AO.
- Панели обзора — **широкие экранные панели** (центральная, две боковые, верхняя, нижняя-«в пол»), у каждой отдельный объект + ставень `ArmorShutter_*` (жалюзи, которые закрываются при повреждении; рабочие шарниры/оси в `cockpit_rig.json`).
- Анимируемые элементы с осями и пределами в `cockpit_rig.json`: рычаги, тумблеры, ленточные индикаторы, трясущиеся подвесные плафоны/кабели, ремни, перчатки пилота, ложементы (качка), крышки панелей, форсунки пара (`Emitter_Steam_NN`), точки искр (`Emitter_Spark_NN`), точки утечки (`Leak_NN`).
- **Руки пилота в перчатках** (низкополигональные, но чистые) в рамах: скелет `PilotRig` с кистями (пальцы — 3 кости на каждый), IK-цели; управляющие рукояти и кнопки в пальцах.
- Свет: маркеры `Light_*` для точечных огней (оранжевые/белые/красные аварийные). Превью с «красивым освещением» (постер-уровень): `preview_eye_view.png`, `preview_wide.png`, `preview_damage_layout.png`, `preview_pilot.png`, `preview_night.png` (ночной сценарий с аварийными огнями).
