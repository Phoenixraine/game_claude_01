# TASK-009 — Набор моделей города (Blender, скрипты) `art/city_kit/`

**Ветка:** `claude/task-009-city-kit` → PR в `main`. **Область:** только `art/city_kit/`.
**Источник:** питч §17, §18, §23 «Масштаб», §29 «Референс 1, 8, 9»; формат района — `docs/tasks/TASK-004-worldgen.md` (читать для типов объектов).

## Цель
Модульный набор городской геометрии, из которого Unreal соберёт район по `district.json`. Скрипты Blender 4.x (`bpy`, окружение — как в TASK-002; если `bpy`
недоступен, писать аккуратно, честно отметить «не запускалось»). Единицы — метры, Z вверх, экспорт FBX по одному файлу на модуль + общий GLB-предпросмотр.
Размер читается деталями (питч §23): окна, этажи, балконы, вентиляция, лестницы, вывески без текста, антенны, водяные баки.

## Состав
1. **Фасадные модули** (ширина 6/12 м, высота этажа 4 м): `Facade_Office_Glass`, `Facade_Office_Concrete`, `Facade_Residential`, `Facade_Industrial`,
   углы, парапеты, цоколи (усиленные нижние этажи, §17), двери/въезды, крыши с оборудованием; по 3 варианта износа/загрязнения. UV по trim-sheet из TASK-008
   (`art/textures/out/trim_sheet/…` — если ещё нет, используйте плейсхолдер-UV по одинаковой схеме и опишите в README).
2. **Hero-здания** (6 штук, имена как в TASK-004): `glass_tower` (220 м, каркас + 4 стадии разрушения: целая → пробита → складывается → обломки), `stadium`,
   `residential_complex`, `overpass` (секции по 40 м со сколами и арматурой), `port_crane` (портальный кран с отдельной стрелой и тросами), `power_station` (подстанция с трансформаторами и катушками).
   Для каждого: целая версия + **пре-фракчер** части (Geometry Collection-friendly: отдельные объекты `Chunk_<NNN>` с внутренними гранями, 150–600 кусков, имена + `chunks.json` с массой и связностью соседей).
3. **Дорога и набережная:** секции дорог (прямая, перекрёсток, поворот, разметка, люки, бордюры), мост-секции, ограждения, причал, швартовые тумбы, волноломы.
4. **Props (instance-friendly):** автомобили (седан, внедорожник, фургон, автобус, грузовик, полицейский, такси — по 2 цвета), контейнеры (3 цвета, 20/40 футов), фонари, светофоры,
   остановки, деревья (3 вида, 2 уровня детализации), кусты, мусорные баки, билборды (пустые), строительные леса, краны малые, антенны, баки, вертолёт гражданский, катера.
5. **Обломки:** бетонные плиты, арматурные пучки, куски фасада, стёкла-осколки, искорёженные автомобили (деформированные версии), кучи щебня — по 4–8 вариантов, для спавна при разрушении.
6. Для каждого объекта: LOD0 ≤ бюджета (авто 15–40 тыс. треугольников, дерево 20 тыс., фасадный модуль ≤ 8 тыс.), пивот логичен, коллизионный прокси `UCX_<имя>_NN` (выпуклые коробки).

## Вывод и проверка
`art/city_kit/out/*.fbx`, `art/city_kit/kit_manifest.json` (имя, категория, bbox, треугольники, пивот, UCX, теги для `district.json`),
превью `art/city_kit/previews/` (витрина по категориям, hero-здания со стадиями разрушения, масштабная сцена «мех-силуэт 82 м у башни 220 м»). Скрипт сам проверяет
имена/бюджеты/UCX/манифест. В PR — реальные команды, результаты, описание превью и слабых мест.

Набор должен быть **токийским**: жилые башни с балконами и блоками кондиционеров, офисные стеклянные/каменные фасады с оконными лентами, низкие магазины и комбини (витрины, навесы, вывески-пустышки с иероглиф-подобными знаками без читаемых слов и без брендов), торговые автоматы, красные фонари, провода и столбы, небольшой храм и ворота,
скоростная эстакада (пилоны Т-образные, парапеты, лампы), мостовые тросы/пилоны, красно-белая решётчатая телебашня (4 ноги, площадки, мачта, ~333 м), вокзал из красного кирпича с куполами, двойная башня мэрии, шарообразное здание, перекрёсток с видеостенами (пустые панели), ограждения каналов, сакуры.
Hero-здания по-прежнему с пре-фракчером (куски `Chunk_NNN`), но **разбивайте на реалистичные неправильные осколки (см. TASK-016)**, а не на кубы. Фасадные модули — с тяжёлым рельефом (балконы, выступы, пожарные лестницы, трубы), 4+ варианта износа, UV по trim-sheet TASK-008. Бюджет и контракт — как выше.
