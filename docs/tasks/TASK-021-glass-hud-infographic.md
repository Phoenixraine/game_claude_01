## Требование владельца
«Большинство экрана занимает стекло, через которое мы смотрим. На него выведи по углам разные штуки: **захват врага**, **проценты брони**, **инфографику, какие части корпуса целы**, и т.д.»

## Раскладка (16:9, центр 60 % кадра свободен)
* **Верхний левый угол:** инфографика собственного корпуса — силуэт меха (спереди), 9 зон ядра (`Head, Torso, Reactor, ShoulderL/R, ArmL/R, LegL/R`), каждая зона = 3 слоя (броня / механизм / система) в виде тонких дуг; цвет по состоянию `Intact…Severed` (питч §21); мигание критических; отваливающиеся плиты — «осколочные» метки.
* **Верхний правый угол:** то же для врага + **рамка захвата** (`lock-on`): уголковые маркеры вокруг цели в мире (в игре позиция берётся из проекции), дальномер, стрелка-подсказка вне экрана, индикатор «цель теряет устойчивость» (стабильность), статусы (ослеплён, заблокированы руки, горит).
* **Нижний левый:** проценты брони общие + по рукам, стабильность, тепло, энергия (приоритет питания), боезапас/кулдауны трёх орудий (иконки без текста).
* **Нижний правый:** ультимейт-шкала, индикатор приоритета питания, мини-радар/компас с позицией врага, счётчик расстояния, часы раунда.
* **Центр:** только прицел-дуга траектории удара (линия, которую рисует игрок), тонкая; предупреждающие кромки по периметру стекла (красная виньетка-«рамка тревоги»), стрелки угрозы с направлением атаки.
* **Тревоги:** слои эффектов повреждений на стекле: трещины (маски), капли, копоть, красные мигающие кромки, глитч-полосы, «потеря сигнала».
Всё — тонкие линии и полупрозрачные контуры, свечение, **без плашек-карточек, без читаемого текста** (числа допустимы только цифрами и «%»; цифры рисуются кодом моноширинным сегментным начертанием в SVG).

## Что сделать
1. `ui/glass_hud/build_hud.py` — генератор SVG-слоёв (источник правды) + PNG-экспорт (RGBA; 2048², для крупных; атласы 1024²) через `cairosvg`/`Pillow` или чистый SVG→PNG своим растеризатором (если библиотек нет — `pip install cairosvg pillow`).
2. Элементы по слоям (каждый — отдельный файл): `silhouette_body_{player,enemy}.svg` (контуры 9 зон с идентификаторами `zone_Head…`), `zone_layers_arcs.svg`, `lockon_corners.svg`, `lockon_ring_anim_strip.png` (раскадровка 16 кадров),
   `bar_armor`, `bar_stability`, `bar_heat`, `bar_energy` (маски-градиенты для материала, заполняются шейдером), `ultimate_gauge`, `weapon_icons_{rockets,rail,plasma}`, `status_icons_{blind,strikelock,burn}`,
   `threat_arrows_{4dir}`, `alarm_frame`, `glitch_strip_NN`, `crack_mask_NN` (8 шт.), `soot_mask_NN`, `rain_drops_atlas`.
3. **Данные** `ui/glass_hud/layout.json`: координаты всех элементов в нормированных долях экрана, якоря, безопасные поля, масштабы для 16:9/21:9/16:10, спецификация привязки к событиям ядра (`EventType` → какой элемент мигает/как реагирует).
   `ui/glass_hud/states.json`: цвета/частоты мигания по состояниям; `ui/glass_hud/schema.json`.
4. **Превью-композиции** (`ui/glass_hud/previews/`): кадр поверх фото-подобного фона (генерируйте фон процедурно: ночной город в тумане), состояния: «бой, всё ок», «средние повреждения», «критично: красная тревога, трещины, горение», «захват врага». Смотрите на PNG, сравнивайте с `ref06`, исправляйте.
5. Тесты: проверка идентификаторов зон и слоёв, непересечение элементов, процент свободного центра ≥ 60 %, цветовой контраст (WCAG-подобный для тонких линий на тёмном/светлом фоне), размеры файлов ≤ 5 МБ каждый.
