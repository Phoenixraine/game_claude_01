# TASK-008 — Процедурные текстуры, декали и спрайт-атласы VFX (`art/textures/`, Python)

**Ветка:** `claude/task-008-textures` → PR в `main`. **Область:** только `art/textures/`.
**Источник:** питч §14 (визуальная модель повреждения), §23 (цвет, мокрые поверхности), §29 (постоянный визуальный блок).

## Цель
Набор PBR-текстур, декалей и спрайтов, генерируемых кодом (Python 3.10+, `numpy`, `Pillow`/`imageio` по доступности; `scipy` по желанию), без внешних
лицензий. Формат: PNG 8/16 бит, размеры степени двойки; тайлящиеся материалы 2048², атласы до 4096². Каждая карта проверяется **глазами**
(сохраняйте превью-сетки и смотрите на них) и численно (тайлится ли шов, диапазоны, средняя яркость).

## Список
**Тайлящиеся PBR-материалы** (комплект: `*_BaseColor.png`, `*_Normal.png` (OpenGL, Y+), `*_ORM.png` (R=AO, G=Roughness, B=Metallic), `*_Height.png`):
`graphite_armor_worn`, `ceramic_gray_panels`, `dark_metal_scratched`, `basalt_armor_worn` (для противника, темнее и с тёмно-красной маркировкой),
`hydraulic_steel`, `rubber_black`, `concrete_weathered`, `concrete_cracked`, `asphalt_wet`, `asphalt_cracked`, `sidewalk_tiles`, `brick_facade`, `glass_curtain_wall`,
`rusty_steel_plate`, `corrugated_metal`, `container_painted_worn`, `water_foam_mask`, `gravel_rubble`.
**Декали** (RGBA, с нормалью/шероховатостью где нужно): царапины (4), вмятины-нормали (4), прожоги/копоть (4), следы масла и охлаждающей жидкости (4),
соль и потёки дождя (4), технические метки и стрелки без читаемого текста, оранжевые маркировочные полосы, швы панелей, вентрешётки, номерные знаки без текста.
**Trim-sheet** для hard-surface мехов: один атлас 4096² с панельными линиями, фасками, заклёпками, шлицами, кабельными каналами + JSON с UV-областями.
**Спрайт-атласы VFX** (flipbook 8×8, RGBA, премультипл.; JSON с параметрами): дым тёмный и светлый, пыль обрушения, пар охлаждения, искры, брызги воды (удар/всплеск),
огонь с дымом, электрическая дуга, осколки стекла, взрыв ракеты (без «ядерных грибов»), капли дождя, волна (кольцо), след снаряда. Анимация получается симуляцией
(например, адвекция шума/жидкостные упрощения), а не тупым вращением одной картинки.
**Градиенты/кривые:** LUT для тепловой индикации, для цветового кода повреждения (нейтральный/жёлтый/оранжевый/красный/чёрный §21).
**Маски:** маски разрушения брони по зонам (Dent, Crack, Burn — по 4 варианта), используются как параметры материала.

## Вывод
`art/textures/out/<имя>/...`, `art/textures/manifest.json` (имя, файлы, размер, tile, цветовое пространство sRGB/Linear для каждого канала — для импорта в UE),
`art/textures/previews/*.png` (сетки превью), `art/textures/README.md`, тесты `art/textures/tests/` (шов тайла: разность краёв ≤ порога; нормали имеют единичную длину;
ORM-каналы в [0,1] и не константа; альфа декалей по краю = 0; атласы имеют ровно 64 кадра и кадры различаются). Суммарно ≤ 400 МБ; файлы > 20 МБ не коммитить —
генерировать `python art/textures/build_all.py` (и добавить запуск в README), в git класть только превью и манифест, если выходные файлы превышают лимит репозитория.
В PR — честный отчёт: что запускалось, что видно на превью, слабые места.
