# TASK-022 — Данные реакции на повреждения: тряска, разрыв труб/проводов, пожары, отлетающие куски, разрушение зданий (`data/damage_fx/`, Python + JSON + тесты)

**Ветка:** `claude/task-022-damage-fx` → PR в `main`. **Область:** `data/damage_fx/` и `docs/ux/damage_fx.md` (папку `data/` делит TASK-006 — файлы не пересекать, использовать подпапку `damage_fx/`).
**Читать:** `docs/STATUS.md` §6A, `docs/CORE_API.md` (события `HitEvent`, `ArmorPlateLost`, `ZoneState`, `LimbSevered`, `ReactorBreach`, `SystemFailure`, `ExternalHit`, `BurnTick`, `StrikeContact`, `BladesClash`),
`core/include/iv/Events.h`, `Body.h`, `docs/pitch/02_pitch/…` §14, §15, §21, `docs/tasks/TASK-016-shards-and-debris.md`.

## Зачем
Игровая часть Unreal превращает каждое событие ядра в эффекты. Сейчас эти значения вшиты в код хаотично. Нужна **единая таблица** (данные + математика + тесты), которую я загружу в Unreal как таблицу, чтобы настраивать «сочность» без перекомпиляции.
Требования владельца: «при ударах по нам всё реально трясётся, трубы рвутся, провода рвутся, пожары, везде варнинг и красные огни; от робота и от нас при ударах отлетают куски, и эти части горят; дом разлетается на части и на крошку и дым при столкновении».

## Что сделать
1. **Профили тряски** (`shake_profiles.json`): для каждого типа события — амплитуда (см/градусы), частота, затухание, формы (шум Перлина/демпфированная синусоида/импульс), направление относительно удара (вектор в системе камеры), «хромата» для стекла,
   длительность; функция `shake_for_event(event_type, damage, zone, layer, blocked)` в `data/damage_fx/fxmath.py` → набор кривых; визуализация (matplotlib → PNG `previews/shake_*.png`). Лимиты: суммарное смещение камеры ≤ 12 см, вращение ≤ 4°, не вызывать укачивания: частоты выше 3.5 Гц гасятся ≤ 0.3 с,
   флаг «уменьшить тряску» (доступность) — множитель 0.25.
2. **Каталог эффектов кабины** (`cockpit_effects.json`) по уровням тяжести S0…S4 (формула тяжести из урона/слоя/зоны/блока): что происходит с трубами/проводами/мониторами/лампами/маяками/пожарами (имена из TASK-020), задержки, длительности, вероятности (детерминированно по сиду события),
   распространение огня (граф Fire_Socket), тушение, красная подсветка кривая интенсивности, сирена, голосовые предупреждения (идентификаторы), глитч мониторов. Функция `plan_cockpit_effects(severity, seed, state)` → детерминированный список команд {t, target, action}.
3. **Отлетающие куски меха** (`mech_chunks.json`): для каждой зоны и слоя — типы кусков (броневая пластина, поршень, шланг, кабель, обломок руки, кусок брони с огнём), число, масса, начальная скорость (направление от точки удара + разброс), вращение, время жизни, огонь/дым (интенсивность и длительность),
   вероятность гореть, осыпь искр при ударе о землю. Привязка к `ArmorPlateLost`/`LimbSevered`/`HitEvent`. Функция `plan_chunks(event, seed)`; **баллистика** симулируется в тесте (проверка, что куски не пролетают сквозь меха и улетают не дальше 120 м).
4. **Разрушение зданий** (`building_destruction.json`): стадии при столкновении (контакт → дробление фасада → обрушение этажей → пыльное облако): число осколков по классам (`TASK-016`: Shard_Concrete_{S,M,L,XL}, Glass_Shard, Gravel, Pebble), массы/скорости/углы разлёта, объём пыли/дыма (кривая во времени), цвет по материалу, длительность,
   частота кадров CPU-частиц (бюджет: ≤ 400 крупных осколков, ≤ 6000 мелких, ≤ 80 дымовых «пуфов» на здание), звуки (id). Для сценариев: удар меча по зданию, удар мехом (`crash`), бросок обломком (`AIVThrownDebris`), попадание плазмы/ракет. Функция `plan_building_break(kind, energy, normal, building_params, seed)`.
5. **Красные огни и предупреждения** (`warnings.json`): список предупреждений (критический урон реактора, потеря руки, перегрев, тревога крюка), приоритеты, цвета, ритмы миганий, звуки, подсказки HUD (id иконок из TASK-021).
6. **Документ** `docs/ux/damage_fx.md` (RU) — как Unreal использует таблицы (последовательность: событие → severity → список команд), перечень всех идентификаторов, диапазоны параметров и «кнопки сочности» (глобальные множители).
7. **Схемы и тесты** (`python -m unittest discover -s data/damage_fx/tests`): валидность JSON по схеме, детерминизм планов, отсутствие NaN, ограничения по бюджетам, проверка на покрытие всех `EventType`, дающих эффект, 100 % зон, отсутствие ссылок на несуществующие идентификаторы.
