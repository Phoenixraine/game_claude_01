# TASK-016 — Библиотека осколков, щебня и обломков для разрушения (Blender, скрипты) `art/shards/`

**Ветка:** `claude/task-016-shards` → PR в `main`. **Область:** только `art/shards/`. **Направление:** `docs/art/DESIGN_BIBLE.md` п.4.

## Цель
Игра ломает здания на **осколки и камушки**. Нужна библиотека лёгких мешей (для инстансинга в Unreal), которая делает обломки выглядящими как настоящий бетон, стекло и сталь, а не кубы.
Окружение Blender — как в TASK-002 (`bpy`; если запустить нельзя — честно отметить, писать аккуратно).

## Состав (имена — контракт; экспорт FBX по группам + GLB + `shards_manifest.json`)
1. `Shard_Concrete_{S,M,L,XL}_NN` — неправильные выпуклые/полувыпуклые осколки бетона (диапазоны размеров 0,25–0,6 / 0,6–1,5 / 1,5–4 / 4–10 условных единиц, по 8–12 вариантов на размер), 40–400 треугольников, с острыми рёбрами, шероховатой «рваной» поверхностью (displace + facet), одной
   гранью-«старой поверхностью» (UV-острова для материала фасада) и остальными гранями — «свежий излом» (отдельный слот `M_Fracture`).
2. `Slab_Concrete_NN` — плиты перекрытия с торчащей арматурой, `Column_Broken_NN` — обломки колонн с арматурой, `Rebar_Bundle_NN`, `Rebar_Single_NN` — прутья (кривые → меши).
3. `Glass_Shard_NN` — треугольные/многоугольные осколки стекла (плоские, 2–40 см условных), `Window_Frame_Broken_NN`.
4. `Pebble_NN` (30 штук) — галька/щебень 3–12 см условных (низкополигональные, 20–60 треугольников, гладкие и угловатые), `Gravel_Cluster_NN` (кластеры из 30–80 камней как один меш для дешёвого рассыпания).
5. `Steel_Plate_Bent_NN`, `Girder_Twisted_NN` (двутавровые балки с изгибом), `Pipe_Broken_NN`, `Cable_Dangling_NN`, `Panel_Facade_Torn_NN` (оторванный кусок фасада с окнами, 3 размера), `AC_Unit_Broken_NN`, `Sign_Torn_NN` (оторванные вывески без текста).
6. **Шаблоны раскола** для разрушения в рантайме: `fracture_patterns.json` — 20 наборов (Voronoi в 3D, радиально-ударный, слоистый «блины» этажей, диагональный) для кубоида размером 1×1×1 в виде списка осколков (каждый — индексы из библиотеки, позиция, ориентация, масштаб), чтобы я мог заменить кубические ячейки здания реальными осколками.
   Скрипт генерации паттернов — `art/shards/lib/fracture.py` (собственная реализация Voronoi + разрез выпуклых ячеек плоскостями, **без** сторонних аддонов, чтобы было воспроизводимо).
7. Материалы (слоты): `M_Concrete_Old`, `M_Fracture`, `M_Glass_Shard`, `M_Steel_Rust`, `M_Rebar`, `M_Gravel`. UV без перекрытий. Масштаб в метрах (1 ед. = 1 м), пивот в центре масс.
8. Коллизионные упрощённые формы: `UCX_*` для L/XL осколков; для мелких — сфера (задаётся в манифесте `radius`).

## Выход и приёмка
`art/shards/out/*.fbx|glb`, `shards_manifest.json` (имя, категория, размерный класс, bbox, треугольники, radius, масса-подсказка), `fracture_patterns.json`, превью `art/shards/previews/` (листы по категориям; сцена «куча обломков»; визуализация 3–4 паттернов раскола), `README.md`, самопроверка в скрипте.
Бюджет всей библиотеки ≤ 300 000 треугольников, каждый меш ≤ 1 500. В PR — реальные команды, результаты, превью, слабые места.

**Эталон вида разрушения: `docs/art/refs/ref05_building_collapse_cockpit.png`** — крупные неправильные плиты, щебень, пыль. Сверяйте формы осколков и композицию листа обломков с ним.
