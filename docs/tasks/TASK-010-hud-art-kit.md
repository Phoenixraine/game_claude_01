# TASK-010 — Графика интерфейса: HUD-кит, иконки, силуэт повреждений (`ui/`, SVG/PNG, Python)

**Ветка:** `claude/task-010-hud-art` → PR в `main`. **Область:** только `ui/`.
**Источник:** питч §21 «Интерфейс боя», §22 «Экраны», референсы `docs/pitch/01_visual_references/03_combat_hud_enemy_attack.png`, `04_damaged_cockpit.png`,
`05_hangar_main_menu.png`; цветовой код §21: целые зоны — нейтральный (бело-голубой), открытая броня — жёлтый, повреждённые механизмы — оранжевый, критические системы —
красный, потерянные части — чёрный. Стиль: тонкие линии, полупрозрачные контуры дополненной реальности на стекле кабины, **без читаемого текста и без плашек-«карточек»**.

## Цель
Набор векторных элементов (SVG — источник правды) и растровых экспортов (PNG с альфой, 2048² для крупных, кратно степени двойки для остальных), которые я подключу
в Unreal как UMG-текстуры/материалы. Все элементы отрисованы кодом (Python, стандартная библиотека + при наличии `cairosvg`/`Pillow`/`numpy` для растеризации); **смотрите на PNG** и
исправляйте то, что выглядит плохо. Отдельный файл `ui/palette.json` с цветами (sRGB hex и linear), толщинами линий и допусками прозрачности.

## Состав (имена файлов — контракт)
1. **Силуэт меха для схемы повреждений:** `ui/svg/mech_silhouette_front.svg` и `..._back.svg` — 9 зон как отдельные `<path id="zone_Head|Torso|Reactor|ShoulderL|ShoulderR|ArmL|ArmR|LegL|LegR">`
   плюс общий контур; подзоны `layer_Armor/Mechanism/System` как тонкие внутренние контуры. Экспорт `mech_zone_masks/<зона>.png` — белая маска на прозрачном, одинакового размера (чтобы в UE красить
   каждую зону параметром материала). Атлас `mech_zone_atlas.png` + JSON с прямоугольниками.
2. **Прицельные элементы:** рамка захвата цели (угловые скобки, 3 размера), пять зон противника (сенсоры, левая рука, центр, правая рука, ноги) как контуры-подсветки, сектор вероятного замаха
   (дуги 8 направлений, 3 уровня уверенности), линия боевого вектора (пунктир с градиентом, 2 толщины), точка контакта, индикатор дистанции.
3. **Индикаторы состояния:** сегментные дуги стабильности и тепла, «поток энергии» (4 приоритета: руки/ноги/защита/оружие — пиктограммы), маркеры боезапаса, шкала согласованности экипажа,
   радар 360° с секторами и силуэтами целей, компас-лента без цифр.
4. **Предупреждения кабины:** 24 пиктограммы (утечка охлаждения, перегрев, потеря сенсора лево/право/верх/перед, гидравлика руки/ноги, пробой брони, отключение питания, захват, прицеливание
   противника, ракета, электричество, вода, обрушение, критический реактор и т. п.) в одном стиле, 128² и 256², моно-белые (цвет задаёт UI) + цветные варианты предупреждений.
5. **Помехи и дефекты стекла:** трещины (8 вариантов, альфа), электронные помехи/строки (тайлящиеся), мигающие панели «потеря камеры» (4 варианта), капли/потёки воды на стекле (6 вариантов), пыль,
   виньетка повреждения (красная аккуратная, 4 силы).
6. **Меню:** геометрические элементы главного меню в ангаре (панель-стекло, разделители, рамки выбора, символы режимов Operations/Duel/Survival/One Frame/Training/Hangar/Settings,
   значки геймпада/клавиатуры для подсказок: кнопки Xbox, PlayStation, мышь, WASD) — без текста.
7. **Контрольный экран:** `ui/previews/hud_mockup.png` — композиция из ваших элементов поверх референса 03 (полупрозрачно), чтобы оценить масштаб/читаемость, и `ui/previews/sheet_*.png` — листы
   со всеми элементами. Скрипт `ui/build_all.py` воспроизводит всё с нуля.

## Приёмка
`python ui/build_all.py` с нуля; тесты `ui/tests/` (все SVG валидны XML, id зон присутствуют ровно один раз, маски одинакового размера и не пустые, палитра совпадает с §21, нет текстовых узлов `<text>`);
в PR — реальные команды, результаты, описание превью, слабые места.
