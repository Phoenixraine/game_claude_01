## Цель
Воспроизводимый скрипт `art/mech/build_bastion.py` (Blender 4.x, `bpy`), который с нуля строит hard-surface модель
меха BASTION-01 высотой **82 м** и экспортирует её для Unreal Engine 5. Результат — не набор кубиков: читаемый силуэт
с массивной грудью, компактной сенсорной головой, утопленной между плечами, мощными гидравлическими руками,
толстыми ногами и стопами, крупными шарнирами и поршнями, панелями с фасками, линиями разъёма, крепежом, кабелями.

## Окружение
`pip install bpy` (Python 3.11 + Blender как модуль) или скачанный Blender portable. Если запуск `bpy` в вашей среде
невозможен — напишите скрипты максимально аккуратно, **честно** отметьте в PR «не запускалось», и приложите, что именно не проверено.
Если запуск возможен — рендерьте превью (Cycles/EEVEE, CPU) и **смотрите на них сами**, итерируйте дизайн.

## Контракт для Unreal (не менять!)
- Единицы: метры; ось вверх +Z, вперёд −Y (стандарт Blender), экспорт FBX с `apply_scale_options='FBX_SCALE_UNITS'`, масштаб 1.0.
  Меха ориентировать лицом к −Y. Начало координат — на земле между стопами.
- **Скелет (Armature `BASTION_Rig`)**, кости ровно с такими именами: `root`, `pelvis`, `torso`, `head`,
  `shoulder_l`, `upperarm_l`, `forearm_l`, `hand_l` (и `_r`), `thigh_l`, `shin_l`, `foot_l` (и `_r`), `reactor` (на спине, дочерняя от `torso`).
  Кости расположены в реальных точках вращения суставов.
- **Меши**: каждая деталь — отдельный объект, жёстко (вес 1.0) привязана к одной кости. Имена:
  `Body_<bone>` для основного корпуса зоны и `Armor_<zone>_<NN>` для съёмных бронепластин (минимум 4–8 на руку/плечо/торс,
  2–4 на голову и ногу), где `<zone>` ∈ {Head, Torso, Reactor, ShoulderL, ShoulderR, ArmL, ArmR, LegL, LegR}.
  Бронепластины должны отделяться без дыр: под ними — внутренняя «механика» (`Inner_<zone>_<NN>`: поршни, кабели, шарниры).
- Отдельно: `Joint_<bone>` — крупные видимые шарниры; `Cable_<zone>_<NN>` — кабели/шланги (кривые → меши).
- **Материалы** (слоты, имена фиксированы): `M_Graphite`, `M_CeramicGray`, `M_DarkMetal`, `M_Hydraulic`, `M_AccentOrange`,
  `M_Rubber`, `M_Glass_Sensor`, `M_Emissive_Status`. У всех — PBR-параметры в Principled BSDF и **UV-развёртка** (не авто-куб, без перекрытий,
  texel density примерно одинаковая). У противника в Unreal подменяются только материалы — не вводить цвета «в геометрию».
- Бюджет: ≤ 450 000 треугольников всего (Nanite). Нормали корректны, без n-gon на фасках, без нулевых граней, манифолд там, где нужно.
- Масштабные детали: окна/люки/лестницы-скобы/посадочные площадки/вентрешётки, чтобы 82 м читались. Читаемость в силуэте важнее мелочи (питч §23).

## Приёмка
1. `blender -b -P art/mech/build_bastion.py` (или `python`) отрабатывает с нуля без ошибок и без интерактива.
2. Скрипт сам проверяет контракт (имена костей/объектов/материалов, вес 1.0, нет объектов без кости, UV есть у всех, бюджет) и падает при нарушении.
3. Все превью сгенерированы и осмысленны. В PR приложены и описаны (что видно, чем недовольны, что улучшено за итерации).
4. Поза-тест: скрипт ставит 3 позы (стойка, замах правой сверху, шаг) и рендерит `preview_pose_*.png` — детали не пересекаются грубо.
5. В PR честно: какие команды запускались, результаты, что не проверено.
