## Часть A. Полировка боевой анимации (первая по ценности)
1. `anim/v2/feel.py`: **слой вторичного движения**: пружины/оверлап на плечах, голове, руках с задержкой (follow-through), «вес» (ease-in-out с разными кривыми на замах/удар/возврат), анти-предвидение (небольшой «замах назад»), контр-вес торса и таза,
   вдавливание стоп при ударе, удар-реакция (`hit_react`) по зонам × силе × слою, отдача оружия, потеря равновесия, подъём после падения.
2. Клипы: `idle_breath`, `walk_heavy` (улучшенный), `turn`, `strike_{up,left,right,down}` (замах/ударная фаза/возврат ×3 скорости), `quick_punch_{l,r}`, `guard_*`, `parry_*`, `dodge_{l,r}` (боковое, масса!), `counter_*`, `clash_recoil`, `stagger_*`, `knockdown`, `getup`,
   `ultimate_*` (подготовка → прыжок → удар), `hit_react_{head,torso,arm_l,arm_r,leg_l,leg_r}_{light,heavy}`, `limp_*` (на основе `damage.py`). Для каждого — длительность, ключевые события для звука/эффектов (`footfall`, `swing_peak`, `impact`).
3. Экспорт в формате, совместимом с `anim/out/*.json` (см. схему) + новый `anim/v2/out/clips_v2.json` (кадры 60 Гц или кривые Безье по суставам), схема `anim/v2/schema.json`, BVH для просмотра. Тесты: пределы суставов не нарушены, стопы не проваливаются/не скользят (допуск), непрерывность на стыках, детерминизм.

## Часть B. Анимации абордажа (человек-пилот + крюк + мех)
Нужен второй скелет — **человек-пилот** (`anim/v2/pilot_rig.py`): ~20 костей (таз, позвоночник×3, голова, ключицы, плечи, локти, кисти, бёдра, колени, стопы), рост 1.8 м, пропорции взрослого; мех-скелет остаётся как есть.
Сцена в мировых координатах меха (82 м), поэтому клипы пилота задаются **в локальной системе якоря** (точка на мехе: `hatch_side` на боку торса / `shoulder_top` на плече / `enemy_hatch_L/R` у стыка вражеского плеча и руки; якоря и их позиции — `anim/v2/anchors.json`, основаны на `rig.py`).
Клипы (длительность — из ТЗ TASK-017; значения-кандидаты в скобках):
 1. `pilot_climb_out` (≈ 3.0 с): открытие бокового люка, вылез, полз по кромке, встал на плечо, страховка.
 2. `pilot_hook_aim` (≈ 1.2 с) и `pilot_hook_fire` (0.5 с): разворот, рука с гарпуном (наручное устройство `GrappleGun`), отдача.
 3. `pilot_hook_flight` (≈ 1.5–2.5 с по расстоянию): полёт на тросе по параболе/маятнику, управляемая поза «ласточка → подготовка к приземлению».
 4. `pilot_land` (0.6 с): гашение инерции, присед, фиксация карабином.
 5. `pilot_hack_loop` (цикл) + `pilot_hack_success`/`pilot_hack_fail`: работа с панелью люка, реакции.
 6. `pilot_grenade_throw` (1.2 с): выдернуть чеку, бросок в люк, закрыть.
 7. `pilot_escape` (≈ 2.0 с): отпрыгнуть/крюк на отход, `pilot_watch_blast` (≈ 1.5 с): поворот в воздухе и «взгляд назад».
 8. `pilot_return_hook` (≈ 2.5 с) и `pilot_climb_in` (≈ 2.5 с).
 9. `pilot_swing_dodge` (≈ 0.9 с): перелёт на другое плечо врага (маятник), `pilot_smashed` (0.4 с): удар/конец.
 10. Реакции меха-хозяина на время абордажа (идёт автопилот): `mech_boarding_idle` (мех стоит в защитной стойке с вытянутой рукой/плечом, страхующее покачивание, минимальные микродвижения, плавные вдохи гидравлики) и реакции меха-врага на посадку пилота: `mech_enemy_swat_windup/swat_strike/swat_miss` (замах руки по плечу, телеграф ≥ 900 мс), `mech_enemy_blast_react_{shoulder_l,shoulder_r}` (взрыв у стыка плеча, отдача, провисание руки).
Траектории троса: `anim/v2/rope.py` — параболы/маятник с провисанием (катенарная аппроксимация) и точками для визуализации (линия 32 сегмента), раскадровка на 60 Гц.
Экспорт: `anim/v2/out/pilot_clips.json`, `anchors.json`, `rope_paths.json`, `events.json` (ключевые события: `hatch_open, foot_plant, hook_fire, hook_hit, grenade_release, blast, hand_grab…`).
