# TASK-012 — Варианты вражеских мехов для режима Breachline (Blender, скрипты) `art/mech_variants/`

**Ветка:** `claude/task-012-variants` → PR в `main`. **Область:** только `art/mech_variants/`. **Зависимость:** TASK-002 влит в `main` (контракт скелета и материалов `art/mech/`, читать `docs/tasks/TASK-002-mech-model.md`).
Если TASK-002 ещё не влит — начните с чтения его ветки/PR и опирайтесь на контракт из описания задачи, **не** дублируйте и не меняйте `art/mech/`.

**Источник:** питч §19 «Выживание: Breachline» — типы противников: быстрый ударный мех; тяжёлый таранщик; захватчик; дальнобойная платформа; мех, атакующий ноги; ремонтная/поддерживающая машина; а также питч §23 (читаемость силуэта).

## Цель
Шесть дополнительных шасси на **том же скелете и тех же именах костей/материалов**, что и BASTION-01 (так анимации, зоны повреждений и код боя работают без изменений), но с **разными пропорциями и силуэтами**, чтобы роль читалась издали:

| Класс | Идея силуэта | Высота |
|---|---|---|
| `STRIKER` | лёгкий, длинные ноги, узкий торс, вынесенные вперёд предплечья-«клинки» | 70 м |
| `RAMMER` | низкий, широкий, огромные плечи-«таран», короткие мощные ноги | 78 м |
| `GRAPPLER` | асимметричные длинные руки с крупными кистями-захватами | 80 м |
| `ARTILLERY` | узкая платформа, плечевой «ствол», раскладные опоры для зафиксированных ног | 82 м |
| `LEGBREAKER` | пониженный центр тяжести, укороченный торс, мощные низкие руки, броня на ногах-«шипах» | 74 м |
| `SUPPORT` | вытянутый корпус с кранами/манипуляторами на спине, светло-серые панели, жёлтые только технические метки | 78 м |

Скрипт `art/mech_variants/build_variants.py` строит каждый вариант параметрически (общий модуль с BASTION не копировать: импортируйте `art/mech/lib/` если он есть, иначе реализуйте собственные примитивы с тем же стилем:
крупные шарниры, поршни, панели с фасками). Требования к экспорту, именам объектов (`Body_*`, `Armor_<zone>_<NN>`, `Inner_*`, `Joint_*`, `Cable_*`), слотам материалов, бюджету (≤ 350 000 треугольников на вариант),
UV и самопроверке — **как в TASK-002**. Противник использует только подмену материалов (базальтовые панели + тёмно-красные метки): сохраняйте слоты.

## Выход и приёмка
`art/mech_variants/out/<CLASS>.fbx` + `.glb` + `<CLASS>_parts.json`, превью на каждый класс (спереди/сбоку/3/4) и **общий лист «все шесть рядом с BASTION-01 в масштабе»** (силуэты должны мгновенно отличаться), `README.md`.
Самопроверка контракта; в PR — реальные команды, результаты, оценка читаемости силуэтов, слабые места.

**Эталон стиля врага: `docs/art/refs/ref02_enemy_mech_sheet.png`** (шипастые плечи, красные сенсоры, когтистые руки, тёмный базальтовый корпус). Классы строятся по этому языку форм.
