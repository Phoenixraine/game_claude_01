# art/textures/ — процедурные текстуры, декали и VFX-атласы (TASK-008)

Всё генерируется кодом (Python, `numpy`, `scipy`, `Pillow`), без внешних ассетов. Тайлы бесшовны **по построению**: шум синтезируется в
частотной области (периодический), клетки Вороного/линии рисуются с заворачиванием краёв, нормали и AO считаются через `np.roll`.
Всё детерминировано (сид — `crc32` от имени карты).

## Запуск

```bash
pip install numpy scipy pillow matplotlib      # matplotlib не нужен
python art/textures/build_all.py               # полный размер: 18 материалов 2048², trim-sheet 4096², атласы 2048², ~5 мин, ~330 МБ PNG
python art/textures/build_all.py --scale 8     # 1/8 разрешения за ~7 с (так работают тесты); manifest пишется рядом с выходом
python art/textures/build_all.py --only vfx    # одна секция: materials-имя, decal, trim, vfx, lut/mask
python -W ignore -m unittest discover -s art/textures/tests    # 22 теста, ~6 с
```

`art/textures/out/` (≈ 330 МБ, ограничение задачи 400 МБ) **не коммитится** — собирается командой выше. В git лежат код, `manifest.json`
(полный размер: имена, файлы, размеры, цветовые пространства по каналам), `previews/*.png` и тесты.

| LUT | тепловая индикация 256×1; цветовой код повреждений §21 256×2 (строка 0 — 5 ступеней: нейтральный бело-голубой, жёлтый, оранжевый, красный, чёрный; строка 1 — плавно) | `out/luts/*.png` |

Соглашения для импорта в UE: BaseColor — sRGB; Normal — Linear, **OpenGL (Y+)**, RGB = n·0,5+0,5 (тест проверяет направление на
искусственной «шишке»; в UE у PNG включить Flip Green Channel, если нужен DirectX); ORM — Linear: R = AO, G = Roughness, B = Metallic;
Height — Linear 8 бит; атласы — премультиплицированный альфа-канал, кадры построчно слева направо сверху вниз.

## Как это проверено

- `python -W ignore -m unittest discover -s art/textures/tests` — **22 теста OK** (сборка в 1/8 разрешения): состав и поля манифеста; шов тайла
  (пара «последняя–первая строка/столбец» не хуже худшей внутренней пары; тест на заведомо непериодической картинке падает); нормали единичной
  длины (±0,02) и смотрят вверх; направление OpenGL; ORM в [0,1], шероховатость не константа, стекло гладкое, резина шероховатая и неметаллическая,
  сталь металлическая; средняя яркость разумна; враг темнее графита, тёмно-красные метки на базальте есть; альфа декалей на всех 4 краях = 0 и
  декаль не пуста; нормали в нормальных декалях единичны; метки — простые формы (≤ 7 компонент связности, т.е. не текст); у каждого атласа 64
  различных видимых кадра, премультипликация (rgb ≤ α), заметная анимация (разность соседних кадров), эффект не «повёрнутая копия» (корреляция
  кадров 12 и 44 < 0,97), нелуповые эффекты затухают; LUT: цвета ступеней, белый/синий концы; маски: 12 штук, значения в [0,1], варианты различаются;
  trim-регионы без дыр и перекрытий; детерминизм (массивы и байты PNG совпадают при повторной сборке).
- Полный прогон `python art/textures/build_all.py`: ~5 мин, 326 МБ; все превью открыты и просмотрены (`previews/materials_01..06.png`,
  `decals.png`, `trim_sheet.png`, `vfx.png`, `luts.png`, `masks.png`).

## Слабые места (честно)

- Материалы читаются как «чистая процедурная» графика, не как сканы: износ — шум + линии + карманы Вороного. Графит и базальт на превью очень тёмные
  (альбедо 0,04–0,1 по питчу §23), без цветового разнообразия; камуфляжные пятна на `ceramic_gray_panels`/`concrete_weathered` повторяются.
- Трещины (`concrete_cracked`, `asphalt_cracked`) выглядят как сетка Вороного («высохшая глина»), без главных магистральных трещин.
- VFX: дым, пыль и огонь на превью обрезаются границей кадра (видны прямоугольные срезы/«блоки»), у дыма и пыли нет тонкой турбулентности; огонь маловат и однороден; всё считалось упрощённой адвекцией на сетке 256², не
  настоящей жидкостной симуляцией; искры/дуга/кольца выглядят лучше всего. Нет отдельных карт освещения (emissive/lit), только цвет+альфа.
- Decals: нормальные декали (вмятины, швы) с шумом на маске; «номерные знаки» — просто пустые рамки.
- Не проверялось в Unreal (импорт, сжатие BC5/BC7, mip-уровни, соответствие trim-sheet UV из `art/mech`). UV `art/mech` пока не использует trim-sheet.
- Нормали шумных материалов (бетон, гравий) в PNG 8 бит весят ~10 МБ; сумма всё равно в лимите.
