# IMPACT VECTOR — дуэль гигантских мехов (Unreal Engine 5.8)

Вид **только из кабины** своего меха, ночной Токио, густой туман (дальше ~100 м ничего не видно) и дождь. Бой на мечах: тяжёлые
медленные удары по траектории, которую рисуешь мышью, блоки и парирования, уклонения, столкновения клинков, ракеты / рельсовое
копьё / плазма, швырок куском здания, ультимейт с добиванием. Противник читает твои линии и отвечает по ним же.

Сначала игра предлагает **обучение** (13 шагов с манекеном), потом **настоящую дуэль**.

## Запуск

* Собранная игра: `F:\IVPackage\Windows\ImpactVector.exe` (если собрана, см. «Сборка»).
* Из редактора: открыть `unreal/ImpactVector/ImpactVector.uproject` (UE 5.8), карта `L_CombatLab`, Play.
  Из-за кириллицы в пути MSVC не собирает проект напрямую: используйте junction `F:\IVUnreal` → `unreal\ImpactVector`
  (`unreal/ImpactVector/Scripts/rebuild.ps1`, `run_game.ps1`).

## Управление

| Действие | Клавиатура + мышь | Геймпад |
|---|---|---|
| Ходьба / бег | W A S D / Shift | левый стик / L3 |
| Обзор | мышь (свободно) | правый стик |
| **Тяжёлый удар мечом** | **зажать ЛКМ и вести мышь — рисуешь траекторию клинка (куда повёл — оттуда замах, где закончил — туда удар: голова, плечи, руки, ноги), отпустить** | RT + правый стик |
| Быстрый удар кулаком | короткий клик ЛКМ | короткое нажатие RT |
| Блок / парирование | ПКМ + мышь в сторону удара; нажать блок в последний момент — парирование | LT + правый стик |
| Жёсткая стойка | Ctrl при блоке | LT + D-pad вниз |
| **Уклонение** (только от боковых ударов!) | Q / E | LB / RB |
| Отмена замаха / ответ на реверс | C / R | B |
| Ракеты (слепят) / Рельсовое копьё (блокирует руки) / Плазма (поджигает) | 1 / 2 / 3 — держать = заряд, отпустить = выстрел | D-pad вверх / влево / вправо |
| Швырнуть здание в лицо врагу | F | A |
| Захват | G | X |
| Ультимейт | V | Y |
| Приоритет питания | стрелки | — |
| Захват цели | Tab | R3 |
| Меню / реванш | Esc / Enter | A |

Правила боя (ядро `core/`): уклонение спасает только от боковых ударов (слева/справа), от ударов сверху и снизу — только блок;
после успешного уклонения или парирования открывается окно контрудара; если оба бьют по одной линии одновременно — клинки
сталкиваются и оба удара гасятся; после оглушения мех на время устойчив к новому оглушению (нет бесконечного стана); ультимейт:
удар второй рукой под грудь, прыжок и удар сверху — ослабленного противника рассекает пополам, здорового лишает свободной
руки и его ультимейта.

## Устройство репозитория

* `core/` — ядро боя на C++17 без зависимостей (60 Гц, детерминированное), тесты `core/tests` (`core/tools/build_tests.cmd` на Windows).
* `unreal/ImpactVector/` — проект UE: `Source/ImpactVector` (игра), `Scripts` (сборка, импорт, материалы), `Content`.
* `art/` — Blender-скрипты: `mech/` (Hunyuan3D → чистка → скиннинг на 19 костей → FBX), `cockpit/` (кабина), `sword/` (меч), `common/`.
* `audio/` — процедурный звук и музыка (`make_battle_music.py`: слои ударных/баса/синтов/лида, меню-петля, стингеры).
* `anim/` — библиотека поз и циклов ходьбы. `worldgen/` — генератор района. `docs/` — питч, дизайн-библия, референсы.

## Сборка

```
powershell unreal/ImpactVector/Scripts/sync_core.ps1       # ядро -> модуль
powershell unreal/ImpactVector/Scripts/rebuild.ps1 -Materials
"E:\epic games\UE_5.8\Engine\Build\BatchFiles\RunUAT.bat" BuildCookRun -project=F:\IVUnreal\ImpactVector.uproject -noP4 ^
  -platform=Win64 -clientconfig=Development -build -cook -stage -pak -archive -archivedirectory=F:\IVPackage
```

Параметры командной строки для тестов: `-IVStart=menu|tutorial|duel`, `-IVStep=N`, `-IVCam=N`, `-IVShots=t1,t2`, `-IVQuit=сек`,
`-IVScript="strike=1@8;stick=-0.7,0@8.1;strike=0@9.6"` (скриптованный ввод), `-IVAutoFight`, `-IVNoAudio`.
