# anim/ — процедурная анимация BASTION-01 (TASK-007)

Библиотека данных и математики на Python (numpy; matplotlib — только для превью): поза = набор углов суставов, между позами —
кривые времени. Всё считается кодом, детерминированно, и экспортируется в JSON/BVH для переноса в Unreal.

## Запуск

```bash
pip install numpy matplotlib                 # matplotlib нужен только для preview
python -m anim.export                        # anim/out/poses.json, locomotion.json, curves.json, schema.json, bvh/*.bvh
python -m anim.preview                       # anim/out/preview/*.png (листы поз и фильмстрипы клипов)
python -W ignore -m unittest discover -s anim/tests   # 48 тестов, ~25 с
```

## Модули

| Файл | Что делает |
|---|---|
| `rig.py` | иерархия 19 костей (контракт TASK-002), геометрия покоя (м), пределы суставов (°), FK, замкнутая двухзвенная IK ноги/руки с проверкой пределов и честным `reachable`, центр масс, контакты стоп |
| `poses.py` | 72 позы + таблица допустимых переходов (`transitions`) |
| `locomotion.py` | шаговый цикл «перенос веса → подъём → мах → постановка», таблица шагов/частот, клипы: ходьба ×3, бег, старт, остановка, поворот на месте влево/вправо |
| `curves.py` | easing с «запаздыванием тяжести», пер-суставный блендинг, пружина-демпфер (инерция кабины/плеч), тряска камеры от шага |
| `damage.py` | `apply_damage(pose, {зона: состояние})`, `limp_walk(damage)` — хромота, повисшая рука, заклиненный локоть, ограниченное плечо |
| `clips.py` | клипы из ключевых поз (замах вверх-вправо, блок, уклонение, быстрый удар, падение) с повторным решением IK ног |
| `export.py`, `schema.py` | экспорт JSON/BVH, мини-валидатор JSON-схем |
| `preview.py` | силуэтные листы поз (спереди/сбоку) и фильмстрипы клипов |

## Соглашения (важно для переноса в Unreal)

- Система координат — как в `art/mech/`: +Z вверх, мех смотрит в **−Y**, его левая сторона — **+X**; метры, градусы.
- Каждый сустав хранит **локальные** углы Эйлера в кадре родителя, `R = Rz(rz)·Ry(ry)·Rx(rx)`; ноль = поза покоя (руки висят,
  все повороты покоя единичные). `rx` — тангаж: у висящей конечности отрицательный `rx` выносит кончик вперёд-вверх, положительный — назад.
  `ry` — отведение (у левой руки отрицательное уводит от тела), `rz` — поворот вокруг оси кости (рыскание для торса/головы).
- Колено — только `shin.rx ∈ [0, 120]` (положительный = пятка назад), локоть — `forearm.rx ∈ [−140, 0]`. Кисть и стопа — 2 DoF, голова — 2 DoF.
  Корень свободный (для падения). Пределы лежат в `poses.json → limits_deg`.
- Рост 82 м, масса ≈ 9 200 т (относительные массы сегментов — `rig.MASS`), длина ноги бедро→лодыжка 37,2 м (бедро 16,0 + голень 21,2).
- Позиции в `poses.json`/`locomotion.json` — в мировых метрах с корнем в начале координат (`root_pos` — смещение корня от покоя).

## Позы (`out/poses.json`, 72 штуки)

`guard_neutral`; 8 замахов (верх/право/лево/низ × правая/левая рука) × 4 фазы (`windup`, `commit`, `strike_end`, `recovery`) = 32;
быстрые удары: `quick_{piston,hook,shove,palm}_{r,l}_{windup,strike}` = 16; блоки `block_{up,right,left,down}`; `hard_stance`;
уклонения `dodge_{left,right,back}_{shift,lift,plant}` (один тяжёлый шаг); `grab_{reach,clamp}`; `ram_{windup,hit}`;
`weapon_charge_{hold,peak}` (плечо раскрыто, ноги зафиксированы широко); `kneel`; `knockdown_{fall,down}`.
Для каждой позы: углы суставов, смещение корня, центр масс, положения ankle/heel/toe каждой стопы и флаг `ground`.
Ноги в позах решает IK по заданным целям стоп (стоят там, где сказано), левые замахи — зеркало правых (тест).
Таблица `transitions`: после `*_recovery` допустимы `guard_neutral`, `hard_stance`, 4 блока, 3 начала уклонения, замахи и быстрые
удары **другой** руки (≥ 6 вариантов; тест проверяет, что позы реально близки — средний разброс суставов < 55°).

## Ходьба (`locomotion.py`, `out/locomotion.json`)

Шаг = интервал между постановками противоположных стоп; цикл = 2 шага. Таз опущен на 7–10 м (иначе опорная нога вытянулась бы
в струну: её длина 37,2 м), опорная стопа неподвижна на земле (нет скольжения), мах — дугой.

| Походка | Длина шага | Период шага | Скорость | Шагов/мин | Высота таза |
|---|---|---|---|---|---|
| walk_slow | 18 м | 4,5 с | 4,0 м/с (14 км/ч) | 13,3 | 36,5 м |
| walk | 22 м | 3,8 с | 5,8 м/с (21 км/ч) | 15,8 | 35,8 м |
| walk_fast | 26 м | 3,0 с | 8,7 м/с (31 км/ч) | 20,0 | 35,1 м |
| run (тяжёлый топот, без полёта) | 28 м | 2,6 с | 10,8 м/с (39 км/ч) | 23,1 | 34,5 м |

Фазы одного шага: перенос веса 22 %, подъём 10 %, мах 48 %, постановка 20 %. Клипы: `walk_slow/walk/walk_fast/run_cycle`,
`walk_start`, `walk_stop`, `turn_left/right` (5 шагов по 16°), `limp_l_walk`, `limp_r_walk`. Кадры — 30 Гц: 19 костей × 3 угла + корень + флаги контакта.

## Кривые (`curves.py`, `out/curves.json`)

`ease_heavy(u) = 1 − (1−u)^2.6`: быстрый старт (наклон 2,6 в нуле) и медленное завершение (наклон 0 в единице); таз/торс/ноги идут с ним
(намерение видно сразу), цепочка плечо→предплечье→кисть — S-кривой с запаздыванием по таймингам (`SWING_TIMING`). Пружина-демпфер
(`Spring`, `secondary_motion`) — инерция кабины/плеч. `step_shake` — тряска камеры: удар в момент постановки, спад за ~⅓ шага.
Клип замаха `swing_up_right` использует тайминги ядра `core/include/iv/Tuning.h`: ход руки 330 мс, восстановление 600 мс, замах до 1 с.

## Повреждения (`damage.py`)

Зоны и состояния — как в TASK-001: `Head, Torso, Reactor, ShoulderL/R, ArmL/R, LegL/R` × `Intact … Severed`. Эффекты: плечо — предел
подъёма сужается (до −35 % диапазона) + провисание; рука — к `Destroyed` повисает, `Critical` — локоть заклинен на −38°, `Severed` — скрывает
предплечье и кисть (`hidden_bones`); нога — жёсткое колено, крен таза к повреждённой стороне, `Critical` — колено заклинено на 14°,
`Destroyed/Severed` — `locomotion_blocked`. `limp_walk`: шаг повреждённой ноги короче на 38 %·s, дольше на 45 %·s, ниже на 60 %·s, подъём
бедра. Измерено: при `Damaged` отношение длин шагов 0,88 / времени маха 0,86, при `Critical` 0,82 / 0,80 (симметричная ходьба = 1,00).

## Что проверено, а что нет

48 тестов (`python -W ignore -m unittest discover -s anim/tests`): все позы и все кадры клипов внутри пределов суставов; IK достигает
100 случайных достижимых целей (ошибка < 1e-6 м) и честно сообщает недостижимость (цель слишком далеко и слишком близко); нет
скольжения опорных стоп во всех клипах (порог 0,25 м/с, получено 0,00–0,12); таблица шагов в диапазоне 18–26 м / 3,0–4,5 с; фазы шага
по порядку, перенос веса до подъёма; детерминизм (побитово одинаковые JSON/BVH); BVH валиден (19 сочленений, число кадров и каналов);
схемы JSON; совместимость recovery с таблицей переходов; асимметрия хромоты > порога; тайминги клипа замаха = тайминги ядра.

Не проверено / слабо (честно):
- **Позы оценены по силуэтам** (`out/preview/*.png`) и числам, не в 3D с мешами `art/mech/` и не в Unreal. Некоторые замахи
  (`swing_*_left`, кросс) выглядят условно; у `knockdown_down` ориентация лёжа — по грубой оценке.
- Пик скорости кисти в замахе — порядка 300–800 м/с при 330 мс хода руки (это следствие тайминга из питча на 82-метровой машине,
  а не физики): для игры это допущение, но с мешами оно будет выглядеть как «взмах без массы», если не добавить визуальную инерцию.
- Ходьба с согнутыми коленями (таз ниже покоя на 7–10 м) — вынужденная при длине шага 18–26 м; «вразвалку» поза читается как приседающая.
- Не делался `blender_preview.py` (опционально): превью — силуэты matplotlib.
- Не сверялось с `art/mech` по реальным длинам: геометрия покоя в `rig.py` взята из параметров `build_bastion.py` вручную.
