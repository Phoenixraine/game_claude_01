# IMPACT VECTOR — контекст проекта

Файтинг от первого лица внутри кабины гигантского меха. Целевой движок — **Unreal Engine 5** (C++ + Blueprints).
Полный питч: `docs/pitch/02_pitch/IMPACT_VECTOR_FULL_PITCH_RU.md` (RU). Референсы: `docs/pitch/01_visual_references/`.

## Разделение работы
- **Локальная машина (владелец + Claude Code + UE5 + Blender):** проект Unreal, арт, модели, сборка, визуальная приёмка.
- **Claude cloud (этот репозиторий):** всё, что можно сделать и проверить на Linux без Unreal: платформенно-независимое
  ядро геймплея на C++17 (`core/`), юнит-тесты, headless-симуляции, баланс-отчёты, документация.
  Ядро потом подключается в Unreal как тонкий слой `UActorComponent`-ов.

## Правила
- Не трогать каталоги вне области задачи (см. `docs/tasks/`). Не коммитить бинарники > 5 МБ и `node_modules`.
- Код `core/` без зависимостей от Unreal и без исключений/RTTI (в UE они по умолчанию выключены). Только стандартная библиотека.
- Детерминизм: фиксированный шаг 60 Гц, собственный сидируемый ГПСЧ, никакого `std::random_device` и системного времени.
- Все числа баланса — в одном месте (`core/include/iv/Tuning.h`) с комментарием-ссылкой на раздел питча.
- Комментарии в коде — по-английски, документация — по-русски.
- Работа ведётся в ветке задачи, результат — Pull Request в `main`. Каждый PR: что сделано, какие тесты реально запускались и с каким результатом, что не проверено.
